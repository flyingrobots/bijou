# Space Grotesk

Space Grotesk by Florian Karsten and the Space Grotesk Project Authors is
distributed under the accompanying SIL Open Font License 1.1 (`OFL.txt`).

Source: [Google Fonts, pinned revision](https://github.com/google/fonts/tree/00a38a53f92aef923b9353f40128e8f4552ddae4/ofl/spacegrotesk).
The upstream `SpaceGrotesk[wght].ttf` is bundled unmodified as `SpaceGrotesk.ttf`.
SHA-256: `acad6de1fc93436f5c0f1f4137751ef04f1aea3063e7036535970ffcfbd79f72`.

The Markdown font demo loads the default outlines of this variable font
(weight 300), compiles the heading characters to bit-packed coverage, and
renders them with Bijou’s raster-font pipeline. It requires no network access.

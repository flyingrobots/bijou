# Version et migration

Cette section publie dans DOGFOOD le récit de la ligne actuelle et les conseils
de migration. Le numéro de version est lu depuis package.json au démarrage; les
pages Release montrent la version actuelle.

## Publié maintenant

- `Nouveautés` pour la version actuelle
- `Récit de version actuel` pour le parcours de lecture du récit
- `Parcours de preuve GraphQL` pour la vraie chaîne NavigationListBlock
- `Historique du CHANGELOG` pour les bornes venant de `docs/CHANGELOG.md`
- `Guide de migration` pour la version actuelle
- le `CHANGELOG.md` court reste le registre des versions et se lit maintenant
  depuis DOGFOOD sans créer une seconde source historique

## Comment utiliser cette section

- Lis d'abord la vue d'ensemble si tu veux la frontière et le récit de version.
- Ouvre `Nouveautés` pour l'explication longue de la ligne de version.
- Ouvre `Récit de version actuel` pour présenter le chemin d'intégrité démo
  v7.2.
- Ouvre `Parcours de preuve GraphQL` pour montrer le GraphQL SDL versionné,
  `bijou-block/1`, `ui-scene-ir/1`, la preuve terminal et les faits debug.
- Ouvre `Historique du CHANGELOG` pour parcourir les bornes de version.
- Ouvre `Guide de migration` si tu mets à jour depuis un major/minor précédent.

## Preuves et état de la version

Une version `alpha`, `beta` ou `rc` est un aperçu. Ouvrir un guide ne prouve ni
la publication d'une version stable ni la répétition de toutes les vérifications
du produit sur cette compilation. Consultez le dossier de version et le suivi
des tickets pour ces décisions. Le parcours GraphQL démontre une chaîne de
preuve ; les documents historiques de version et de conception conservent
le périmètre et les affirmations de leurs versions d'origine.

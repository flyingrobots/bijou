# Navigate DOGFOOD

Use the top-level tabs to transition between major documentation sections.

On the title screen, **Enter** opens the docs, **←/→** changes the theme,
**↑/↓** changes rendering quality, and **Esc/q** requests quit. The Jacquard
cylinder and Space Grotesk prompt are visual treatments of those existing actions.

## Within a Section
- **`Tab`**: Move focus between panes.
- **`Up` / `Down`**: Browse lists or rows.
- **`Page Up` / `Page Down`**: Page through large collections.
- **`j` / `k`**: Scroll prose (also `d`/`u` and `g`/`G`).
- **`/`**: Open global search.
- **`F2`**: Open settings.
- **`F10`**: Open Theme Inspector.
- **`?`**: Toggle help.

## Proving Ground
The `Components` section is the primary proving ground for the library, shell,
and runtime. **Guides → Latest Features** covers the recent font and theme work;
search also indexes its article body. **Packages** includes the MCP adapter.
Articles labeled **Historical reference** come from preserved source records;
use the latest guide and live package READMEs for changes made since those records.

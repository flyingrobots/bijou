# Navegar por DOGFOOD

Usa las pestañas de nivel superior para pasar de una sección principal de la documentación a otra.

En la pantalla de título, **Enter** abre la documentación, **←/→** cambia el tema,
**↑/↓** cambia la calidad de renderizado y **Esc/q** solicita salir. El cilindro
Jacquard y el indicador en Space Grotesk son tratamientos visuales de esas mismas acciones.

## Dentro de una sección
- **`Tab`**: Mueve el foco entre paneles.
- **`Up` / `Down`**: Recorre listas o filas.
- **`Page Up` / `Page Down`**: Pasa página en colecciones grandes.
- **`j` / `k`**: Desplaza la prosa (también `d`/`u` y `g`/`G`).
- **`/`**: Abre la búsqueda global.
- **`F2`**: Abre los ajustes.
- **`F10`**: Abre el Theme Inspector.
- **`?`**: Muestra u oculta la ayuda.

## Banco de pruebas
La sección `Components` es el principal banco de pruebas de la biblioteca, el shell
y el runtime. **Guides → Latest Features** cubre el trabajo reciente en fuentes y temas;
la búsqueda también indexa el cuerpo de ese artículo. **Packages** incluye el adaptador MCP.
Los artículos marcados como **Historical reference** proceden de registros fuente preservados;
consulta la guía más reciente y los README actuales de los paquetes para los cambios posteriores a esos registros.

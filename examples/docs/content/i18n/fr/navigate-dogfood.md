# Naviguer dans DOGFOOD

Utilisez les onglets de premier niveau pour passer d’une grande section de la documentation à une autre.

Sur l’écran titre, **Enter** ouvre la documentation, **←/→** change le thème,
**↑/↓** change la qualité de rendu et **Esc/q** demande à quitter. Le cylindre
Jacquard et l’invite en Space Grotesk sont des habillages visuels de ces actions existantes.

## Dans une section
- **`Tab`** : déplacer le focus entre les volets.
- **`Up` / `Down`** : parcourir les listes ou les lignes.
- **`Page Up` / `Page Down`** : paginer dans les grandes collections.
- **`j` / `k`** : faire défiler la prose (également `d`/`u` et `g`/`G`).
- **`/`** : ouvrir la recherche globale.
- **`F2`** : ouvrir les réglages.
- **`F10`** : ouvrir l’inspecteur de thème.
- **`?`** : afficher ou masquer l’aide.

## Terrain d’essai
La section `Components` est le principal terrain d’essai de la bibliothèque, du shell
et du runtime. **Guides → Latest Features** couvre les travaux récents sur les polices et les thèmes ;
la recherche indexe aussi le corps de cet article. **Packages** inclut l’adaptateur MCP.
Les articles marqués **Historical reference** proviennent d’archives sources préservées ;
consultez le guide le plus récent et les README des paquets en vigueur pour les changements postérieurs à ces archives.

# A printed page

This document is rendered by **Bijou**. Choose a Google Fonts family or supply your own font.

## A readable document

Body text stays at the terminal’s normal size. Headings, lists, links, tables,
quotes, and code use Bijou’s existing Markdown renderer.

- Pass your own Markdown filepath.
- Search Google Fonts or pass `--font /path/to/font.ttf`.
- Scroll using your terminal’s scrollback.
- Pipe the output to keep ordinary text headings.

> A typeface gives a page its voice.

```markdown
# This is code, not a raster heading
```

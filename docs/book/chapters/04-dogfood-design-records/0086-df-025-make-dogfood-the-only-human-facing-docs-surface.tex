\section{Sponsor human}\label{record-086-sponsor-human}

A builder or maintainer who should have exactly one obvious answer to ``where do I go to learn Bijou?''

\section{Sponsor agent}\label{record-086-sponsor-agent}

An agent that must determine, from repo artifacts alone, whether the public docs surface is DOGFOOD or the \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} tree.

\section{Hill}\label{record-086-hill}

DOGFOOD is the only human-facing docs surface for Bijou. The \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} tree remains useful, but only as a secondary/internal reference, regression, and migration substrate rather than a competing public docs front door.

\section{Why this cycle exists}\label{record-086-why-this-cycle-exists}

The repo currently carries two conflicting truths:

\begin{itemize}
\tightlist
\item
  strategy docs say DOGFOOD should replace example sprawl as the living docs system
\item
  front-door docs and release validation still treat \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} as a first-class public teaching path
\end{itemize}

That is not a harmless wording issue.

If humans still have to browse \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}R\allowbreak{}E\allowbreak{}A\allowbreak{}D\allowbreak{}M\allowbreak{}E\allowbreak{}.\allowbreak{}m\allowbreak{}d} to understand the product, then DOGFOOD is not actually the docs surface yet. It is just a better example.

For \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}, Bijou needs a sharper stance:

\begin{itemize}
\tightlist
\item
  DOGFOOD is where humans should learn Bijou
\item
  example programs are secondary and should not compete with DOGFOOD for repo-front-door authority
\item
  release smoke should follow the same truth instead of continuing to bless the broad examples tree as the main proving surface
\end{itemize}

A curious builder evaluating Bijou and trying to find the canonical docs path quickly.

\begin{itemize}

\item
  treat \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} as secondary reference material, not as the main product documentation surface
\end{itemize}

\section{Accessibility / assistive reading posture}\label{record-086-accessibility-assistive-reading-posture}

This is a docs-information-architecture cycle. The important accessibility requirement is clarity: people using plain-text docs, terminal readers, or agent tooling should not have to infer canon from inconsistent link placement or filenames.

\section{Localization / directionality posture}\label{record-086-localization-directionality-posture}

This cycle does not add new localized copy requirements. It does require that section naming and docs routing remain cleanly separable from English-only filesystem trivia such as \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}o\allowbreak{}c\allowbreak{}s}.

\subsection{Why that matters}\label{record-086-why-that-matters}

If examples remain both:

\begin{itemize}
\tightlist
\item
  a public docs front door
\item
  and the main release smoke contract
\end{itemize}

then DOGFOOD cannot honestly be called ``the only way'' yet.

\section{Decision}\label{record-086-decision}

\subsection{\texorpdfstring{Public-docs rule for \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}}{Public-docs rule for }}\label{record-086-public-docs-rule-for-4.1.0}

For \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}, DOGFOOD is the only human-facing docs surface.

That means:

\begin{itemize}
\tightlist
\item
  root docs should send humans to DOGFOOD first
\item
  package/design/release corpus should be reachable through DOGFOOD
\item
  the example inventory should read as secondary/internal/reference material
\item
  release smoke should move off the broad \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} tree
\end{itemize}

\subsection{Example posture}\label{record-086-example-posture}

Examples still matter, but their role is narrower:

\begin{itemize}
\tightlist
\item
  migration references
\item
  isolated API seam proofs
\item
  targeted regression fixtures
\item
  implementation sandboxes
\end{itemize}

They do \textbf{not} get to remain a competing public docs navigation layer.

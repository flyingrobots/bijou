\section{Sponsor human}\label{record-085-sponsor-human}

A builder or maintainer who wants DOGFOOD to explain not just what Bijou exports, but why the framework is shaped the way it is.

\section{Sponsor agent}\label{record-085-sponsor-agent}

An agent that must answer:

\begin{itemize}
\tightlist
\item
  what doctrine governs Bijou runtime and modeling decisions
\item
  how the repo is architected
\item
  which invariants matter
\item
  where the design-system and UX stance live
\end{itemize}

\section{Hill}\label{record-085-hill}

The \texttt{P\allowbreak{}h\allowbreak{}i\allowbreak{}l\allowbreak{}o\allowbreak{}s\allowbreak{}o\allowbreak{}p\allowbreak{}h\allowbreak{}y} section in DOGFOOD stops being a placeholder and becomes a real reader-first home for doctrine, architecture, invariants, and design-system guidance.

\section{Why this cycle exists}\label{record-085-why-this-cycle-exists}

After \texttt{D\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}2\allowbreak{}3}, DOGFOOD could explain the repo, the package line, and the release line, but it still could not explain Bijou's design stance without sending users back into raw repo docs.

That was the last major corpus gap keeping DOGFOOD from acting like a real docs product for \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}.

\section{Playback questions}\label{record-085-playback-questions}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Does the \texttt{P\allowbreak{}h\allowbreak{}i\allowbreak{}l\allowbreak{}o\allowbreak{}s\allowbreak{}o\allowbreak{}p\allowbreak{}h\allowbreak{}y} section now expose more than an overview page?
\item
  Are key doctrine and architecture docs reachable from inside the app?
\item
  Can a user read runtime-truth doctrine, architecture, invariants, and design-system guidance without leaving DOGFOOD?
\item
  Do the blocker lane and signposts stop pretending \texttt{D\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}2\allowbreak{}4} is still open?
\item
  Are the remaining \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} blockers now only the examples/smoke posture items?
\end{enumerate}

\section{Accessibility / assistive reading posture}\label{record-085-accessibility-assistive-reading-posture}

The newly published corpus must remain scrollable, keyboard-first, and text-legible inside the existing prose-reader shell.

\section{Localization / directionality posture}\label{record-085-localization-directionality-posture}

This cycle does not translate the doctrine corpus, but it must keep the same localizable shell and section posture established in \texttt{D\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}2\allowbreak{}2}.

\section{Agent inspectability / explainability posture}\label{record-085-agent-inspectability-explainability-posture}

An agent should be able to prove closure by inspecting:

\begin{itemize}
\tightlist
\item
  the new \texttt{P\allowbreak{}h\allowbreak{}i\allowbreak{}l\allowbreak{}o\allowbreak{}s\allowbreak{}o\allowbreak{}p\allowbreak{}h\allowbreak{}y} guide entries in the DOGFOOD app
\item
  the cycle doc
\item
  the updated \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} blocker lane
\item
  the release signposts
\item
  the cycle tests
\end{itemize}

\section{Non-goals}\label{record-085-non-goals}

\begin{itemize}
\tightlist
\item
  replacing the source docs under \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/}
\item
  finishing the examples-to-DOGFOOD posture shift
\item
  replacing the release smoke contract
\item
  changing the \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} version decision
\end{itemize}

\section{Decision}\label{record-085-decision}

For \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}, DOGFOOD should publish the key doctrine and architecture corpus through the \texttt{P\allowbreak{}h\allowbreak{}i\allowbreak{}l\allowbreak{}o\allowbreak{}s\allowbreak{}o\allowbreak{}p\allowbreak{}h\allowbreak{}y} section instead of treating that section as an empty promise.

The repo-owned docs remain the source of truth. DOGFOOD becomes the canonical human-facing reading surface for them.

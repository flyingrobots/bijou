\section{Framing}\label{record-102-framing}

Overlay primitives are the family for layered UI that is not ordinary document flow: \texttt{t\allowbreak{}o\allowbreak{}o\allowbreak{}l\allowbreak{}t\allowbreak{}i\allowbreak{}p\allowbreak{}(\allowbreak{})}, \texttt{d\allowbreak{}r\allowbreak{}a\allowbreak{}w\allowbreak{}e\allowbreak{}r\allowbreak{}(\allowbreak{})}, \texttt{m\allowbreak{}o\allowbreak{}d\allowbreak{}a\allowbreak{}l\allowbreak{}(\allowbreak{})}, and \texttt{t\allowbreak{}o\allowbreak{}a\allowbreak{}s\allowbreak{}t\allowbreak{}(\allowbreak{})}. They differ by interruption level. Tooltips explain locally, drawers supplement, modals block, and toasts announce transiently.

This audit verifies overlay primitive stories against real story rendering, component-family doctrine, and mode-aware lowerings. It also closes the story drift where DOGFOOD already had modal and toast examples, but did not visibly exercise drawer or tooltip primitives as part of the same overlay family.

\section{Drift Check}\label{record-102-drift-check}

Runtime support already existed for all four primitives. The drift was in DOGFOOD: \texttt{m\allowbreak{}o\allowbreak{}d\allowbreak{}a\allowbreak{}l\allowbreak{}(\allowbreak{})} and \texttt{t\allowbreak{}o\allowbreak{}a\allowbreak{}s\allowbreak{}t\allowbreak{}(\allowbreak{})} were visible, but \texttt{d\allowbreak{}r\allowbreak{}a\allowbreak{}w\allowbreak{}e\allowbreak{}r\allowbreak{}(\allowbreak{})} and \texttt{t\allowbreak{}o\allowbreak{}o\allowbreak{}l\allowbreak{}t\allowbreak{}i\allowbreak{}p\allowbreak{}(\allowbreak{})} were only documented indirectly.

This slice fixes the drift by adding the missing stories and making constrained lowerings explicitly textual. No runtime API changes were required.

\section{Retrospective}\label{record-102-retrospective}

The useful release work was not inventing another overlay. It was making DOGFOOD teach the existing overlay hierarchy honestly: explain with a tooltip, supplement with a drawer, block with a modal, and announce briefly with a toast.

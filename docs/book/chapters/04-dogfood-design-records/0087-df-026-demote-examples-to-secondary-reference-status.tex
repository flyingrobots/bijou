\section{Sponsor human}\label{record-087-sponsor-human}

A learner or evaluator who should get one clear answer about where to start reading Bijou docs, instead of being bounced between DOGFOOD and a parallel example hub.

\section{Sponsor agent}\label{record-087-sponsor-agent}

An agent that must tell the difference between:

\begin{itemize}
\tightlist
\item
  the canonical docs surface
\item
  the internal example inventory
\item
  migration/reference fixtures
\item
  smoke and regression substrate
\end{itemize}

\section{Hill}\label{record-087-hill}

The repo stops presenting \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} as a competing docs product. DOGFOOD is the canonical human-facing path. Examples remain valuable, but only as secondary/internal/reference material.

\section{Why this cycle exists}\label{record-087-why-this-cycle-exists}

\texttt{D\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}2\allowbreak{}5} set the policy direction, but policy alone was not enough.

If DOGFOOD says ``start here'' while the example inventory still reads like a second docs hub, the public posture is still split.

This cycle exists to make the repo-facing surfaces honest before \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}.

\section{Playback questions}\label{record-087-playback-questions}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Do front-door docs still clearly tell humans to start with DOGFOOD?
\item
  Does the example inventory now read as secondary/internal/reference instead of a public docs hub?
\item
  Can a user open DOGFOOD itself and understand why examples are secondary?
\item
  Do release-facing docs stop treating the example inventory as equal public navigation?
\item
  Is \texttt{W\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}0\allowbreak{}3} now the only remaining \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} blocker?
\end{enumerate}

\section{Accessibility / assistive reading posture}\label{record-087-accessibility-assistive-reading-posture}

The examples posture should be stated in text, not implied by color, layout, or repo folklore.

\section{Localization / directionality posture}\label{record-087-localization-directionality-posture}

This cycle does not translate the example posture copy, but it must keep the explanation inside the same localizable DOGFOOD shell.

\section{Agent inspectability / explainability posture}\label{record-087-agent-inspectability-explainability-posture}

An agent should be able to prove closure by inspecting:

\begin{itemize}
\tightlist
\item
  \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}D\allowbreak{}O\allowbreak{}G\allowbreak{}F\allowbreak{}O\allowbreak{}O\allowbreak{}D\allowbreak{}.\allowbreak{}m\allowbreak{}d}
\item
  \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}E\allowbreak{}X\allowbreak{}A\allowbreak{}M\allowbreak{}P\allowbreak{}L\allowbreak{}E\allowbreak{}S\allowbreak{}.\allowbreak{}m\allowbreak{}d}
\item
  \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}R\allowbreak{}E\allowbreak{}A\allowbreak{}D\allowbreak{}M\allowbreak{}E\allowbreak{}.\allowbreak{}m\allowbreak{}d}
\item
  the DOGFOOD guide corpus
\item
  the \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} blocker lane
\item
  the cycle tests
\end{itemize}

\section{Non-goals}\label{record-087-non-goals}

\begin{itemize}
\tightlist
\item
  deleting the whole \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} tree
\item
  replacing the release smoke contract
\item
  erasing migration or isolated API seam references that still matter
\end{itemize}

\section{Decision}\label{record-087-decision}

For \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}, DOGFOOD is the only human-facing docs surface. The example inventory remains, but it should read as:

\begin{itemize}
\tightlist
\item
  secondary/internal reference
\item
  migration substrate
\item
  isolated API proof
\item
  regression/smoke substrate
\end{itemize}

\section{Implementation outline}\label{record-087-implementation-outline}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Publish the secondary-example posture inside DOGFOOD itself.
\item
  Tighten \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}E\allowbreak{}X\allowbreak{}A\allowbreak{}M\allowbreak{}P\allowbreak{}L\allowbreak{}E\allowbreak{}S\allowbreak{}.\allowbreak{}m\allowbreak{}d} so it reads as an internal reference map.
\item
  Tighten \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}R\allowbreak{}E\allowbreak{}A\allowbreak{}D\allowbreak{}M\allowbreak{}E\allowbreak{}.\allowbreak{}m\allowbreak{}d} so it does not read like a docs hub.
\item
  Move \texttt{D\allowbreak{}F\allowbreak{}-\allowbreak{}0\allowbreak{}2\allowbreak{}6} from the \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} blocker lane into \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}e\allowbreak{}s\allowbreak{}i\allowbreak{}g\allowbreak{}n\allowbreak{}/} and update the signposts/tests.
\end{enumerate}

\section{Why this cycle exists}\label{record-070-why-this-cycle-exists}

DF-007 proved the coverage ratchet can keep moving while staying focused on real product value.

The next promised step is now explicit:

\begin{itemize}
\tightlist
\item
  DOGFOOD currently documents 11 of 35 component families
\item
  the enforced floor is 29\%
\item
  the next declared target is 34\%
\end{itemize}

This cycle exists to earn that next target through the documentation-oriented families that make DOGFOOD feel more like a real field guide: bounded markdown prose and explicit linked destinations.

\section{Scope of this cycle}\label{record-070-scope-of-this-cycle}

This cycle intentionally covers:

\begin{itemize}
\tightlist
\item
  adding enough real DOGFOOD component stories to move coverage from 11 to 13 families
\item
  documenting \texttt{m\allowbreak{}a\allowbreak{}r\allowbreak{}k\allowbreak{}d\allowbreak{}o\allowbreak{}w\allowbreak{}n\allowbreak{}(\allowbreak{})} as the bounded formatted-document family
\item
  documenting \texttt{h\allowbreak{}y\allowbreak{}p\allowbreak{}e\allowbreak{}r\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}k\allowbreak{}(\allowbreak{})} as the explicit link/destination family
\item
  raising the enforced floor from 29\% to 34\%
\item
  raising the next declared target from 34\% to 39\%
\end{itemize}

It does \textbf{not} include:

\begin{itemize}
\tightlist
\item
  broad docs-shell redesign
\item
  full reference-doc navigation or pager workflows
\item
  introducing new component families into the canonical denominator
\item
  pretending DOGFOOD is now complete
\end{itemize}

A builder evaluating whether DOGFOOD can now teach reference-style prose and explicit links as real Bijou surfaces instead of only showcasing status, overlays, and inspection panes.

\begin{itemize}

  one story that shows \texttt{m\allowbreak{}a\allowbreak{}r\allowbreak{}k\allowbreak{}d\allowbreak{}o\allowbreak{}w\allowbreak{}n\allowbreak{}(\allowbreak{})} as bounded structured prose, not a substitute layout engine
\item
  one story that shows \texttt{h\allowbreak{}y\allowbreak{}p\allowbreak{}e\allowbreak{}r\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}k\allowbreak{}(\allowbreak{})} as an honest terminal destination primitive with fallback behavior
\item
  coverage progress that rises only because those documentation-oriented families are genuinely present
\end{itemize}

\subsection{Human hill}\label{record-070-human-hill}

A user can open DOGFOOD, learn when to use \texttt{m\allowbreak{}a\allowbreak{}r\allowbreak{}k\allowbreak{}d\allowbreak{}o\allowbreak{}w\allowbreak{}n\allowbreak{}(\allowbreak{})} and \texttt{h\allowbreak{}y\allowbreak{}p\allowbreak{}e\allowbreak{}r\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}k\allowbreak{}(\allowbreak{})}, and see the coverage number rise because the field guide now actually covers those reference surfaces.

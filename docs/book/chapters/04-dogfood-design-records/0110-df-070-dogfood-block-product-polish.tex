\section{Sponsor Human}\label{record-110-sponsor-human}

DOGFOOD should stop feeling like a contract debugger for Blocks and start feeling like a terminal product authored from Blocks.

\section{Sponsor Agent}\label{record-110-sponsor-agent}

An agent should be able to inspect DOGFOOD and see that semantic Blocks own the major product surfaces, while prose, navigation, preview, and settings behavior remain observable through tests instead of hand-audited screenshots.

\section{Hill}\label{record-110-hill}

DOGFOOD moves from ``Blocks are documented here'' toward ``DOGFOOD is materially built from Blocks.'' The first proof is product polish: word-aware prose wrapping, block-owned documentation and navigation surfaces, block-owned inspector/settings surfaces, and block/story preview parity without inventing new provider, lifecycle, localization, or callback rules.

\section{Core Rule}\label{record-110-core-rule}

Rendered DOGFOOD polish must consume existing contracts.

That means:

\begin{itemize}
\tightlist
\item
  prose wrapping belongs at text/prose boundaries, not arbitrary surface clipping
\item
  Blocks own semantic product regions
\item
  components remain the leaf rendering vocabulary
\item
  localization goes through the localization port
\item
  data flow stays unidirectional
\item
  story and block previews should share the same shell assumptions
\end{itemize}

\section{Non-Goals}\label{record-110-non-goals}

\begin{itemize}
\tightlist
\item
  no new provider lifecycle system
\item
  no hidden global block registry
\item
  no broad visual redesign
\item
  no conversion of every leaf component into a Block
\item
  no AppFrame rewrite
\item
  no localization runtime rewrite
\item
  no tests that assert prose documentation wording instead of rendered behavior
\end{itemize}

\section{Tests To Write First}\label{record-110-tests-to-write-first}

\begin{itemize}
\tightlist
\item
  behavior tests proving prose wrapping breaks at word boundaries where possible
\item
  behavior tests proving DOGFOOD article/navigation surfaces use the same rendered output paths their Blocks publish
\item
  behavior tests proving block discovery and preview indexing do not execute unrelated render paths
\item
  behavior tests proving locale persistence and catalog coverage changes remain behind the localization port
\end{itemize}

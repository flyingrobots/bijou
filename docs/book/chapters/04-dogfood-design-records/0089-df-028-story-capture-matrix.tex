\section{Framing}\label{record-089-framing}

Bijou's best components are not single screenshots. They have rich, interactive, static, pipe, and accessible renderings, often across multiple variants and widths. Docs and tests need one place to see that matrix without copying examples by hand.

DF-028 adds a pure story capture matrix. The first slice accepts story profiles, variants, and a renderer callback, captures every profile/variant combination, and renders deterministic text. It is intentionally renderer-neutral: callers can use core components, TUI frames, fixtures, or DOGFOOD stories around it.

\section{Sponsored Users}\label{record-089-sponsored-users}

\begin{itemize}
\tightlist
\item
  Maintainers auditing multi-mode component stories.
\item
  Docs authors promoting regression fixtures into readable examples.
\item
  MCP/tooling authors exporting the same capture facts to agents.
\item
  Accessibility reviewers comparing lowerings without opening a TUI.
\end{itemize}

\section{Hills}\label{record-089-hills}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  A maintainer can capture every variant across interactive, static, pipe, and accessible profiles from one renderer callback.
\item
  A reviewer can see missing required modes before accepting a story capture.
\item
  A docs surface can render the captured matrix as stable text.
\end{enumerate}

\section{Acceptance Criteria}\label{record-089-acceptance-criteria}

\begin{itemize}
\tightlist
\item
  RED tests fail before implementation and pass after.
\item
  Captures are deterministic and cover the profile/variant cross product.
\item
  Missing required modes are stable and sorted by output-mode order.
\item
  Text output is suitable for docs, test failures, and agent reports.
\item
  Docs and changelog describe the helper.
\end{itemize}

\section{Drift Check}\label{record-089-drift-check}

\begin{itemize}
\tightlist
\item
  Scope stayed renderer-neutral. The helper executes a caller-provided renderer and records string output, leaving surface conversion and runtime/test adapter orchestration to future wrappers.
\item
  The matrix can carry DX-025 component metadata but does not validate or own it.
\item
  Missing required modes are sorted by Bijou output-mode order.
\end{itemize}

\section{Retrospective}\label{record-089-retrospective}

\begin{itemize}
\tightlist
\item
  Keeping rendering caller-owned makes the helper useful in core tests, DOGFOOD, TUI fixtures, and MCP payload generation without importing runtime adapters.
\item
  The next useful layer is a fixture/story wrapper that supplies profiles and renderer contexts automatically, then writes the matrix into docs artifacts.
\end{itemize}

\section{Human users}\label{record-080-human-users}

\subsection{Primary human user}\label{record-080-primary-human-user}

A builder evaluating whether Bijou can teach expressive and animated surfaces honestly instead of treating them as decorative afterthoughts.

\subsection{Human hill}\label{record-080-human-hill}

\section{Agent users}\label{record-080-agent-users}

\subsection{Primary agent user}\label{record-080-primary-agent-user}

\subsection{Agent hill}\label{record-080-agent-hill}

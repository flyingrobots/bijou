\section{Decision Summary}\label{record-115-decision-summary}

DOGFOOD should absorb the three most visible post-release polish findings from the \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} sanity pass without expanding into a broad shell redesign:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Disable the hidden double-\texttt{T\allowbreak{}a\allowbreak{}b} footer toggle until the AppShell has a visible command, animation, and restore affordance.
\item
  Restyle the quit confirmation so it is compact, themed, aligned, and easy to answer in the default theme.
\item
  Make the Blocks section lead with \texttt{C\allowbreak{}o\allowbreak{}u\allowbreak{}n\allowbreak{}t\allowbreak{}e\allowbreak{}r\allowbreak{}D\allowbreak{}e\allowbreak{}m\allowbreak{}o\allowbreak{}B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k}, because that is the most alive interactive proof of what Blocks are.
\end{enumerate}

\section{Sponsored Human}\label{record-115-sponsored-human}

A DOGFOOD user wants the docs app to feel deliberate after \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}: no hidden state that leaves terminal background behind, no awkward quit prompt, and a Blocks page that immediately demonstrates an interactive block instead of starting on descriptive prose.

\section{Sponsored Agent}\label{record-115-sponsored-agent}

An agent wants deterministic behavior to assert: footer visibility should not change through undocumented key timing, the quit dialog should have stable themed geometry, and the Blocks default route should identify the same guide id that renders the interactive counter proof.

\section{Hill}\label{record-115-hill}

DOGFOOD can start the post-\texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} era with a cleaner shell and a stronger Blocks first impression while keeping the patch small, testable, and isolated from V8 product-contract work.

\section{Scope}\label{record-115-scope}

\subsection{Disable Hidden Footer Toggle}\label{record-115-disable-hidden-footer-toggle}

The current hidden double-\texttt{T\allowbreak{}a\allowbreak{}b} footer toggle is not discoverable. When hidden, it can expose uncolored terminal background and does not explain how to recover the footer. This cycle should remove that key path from normal DOGFOOD/AppShell input handling. \texttt{T\allowbreak{}a\allowbreak{}b} should remain the normal focus traversal key.

This does not forbid a future footer command. A future version can reintroduce footer visibility as an explicit command with visible state, animation, help text, and theme-safe repaint behavior.

\subsection{Restyle Quit Confirmation}\label{record-115-restyle-quit-confirmation}

The quit confirmation should render as a compact modal rather than a tall, skinny prompt. Its background, border, title, body, and actions should use the selected frame theme instead of leaving unthemed terminal patches.

The action labels must be readable in the default DOGFOOD theme. The dialog should keep the existing command contract: confirm quits, reject closes the dialog, and normal app state remains underneath.

\subsection{Counter-First Blocks}\label{record-115-counter-first-blocks}

The Blocks section should open directly on \texttt{C\allowbreak{}o\allowbreak{}u\allowbreak{}n\allowbreak{}t\allowbreak{}e\allowbreak{}r\allowbreak{}D\allowbreak{}e\allowbreak{}m\allowbreak{}o\allowbreak{}B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k}. Selecting the \texttt{B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{} \allowbreak{}P\allowbreak{}r\allowbreak{}e\allowbreak{}v\allowbreak{}i\allowbreak{}e\allowbreak{}w} parent row should also route to \texttt{C\allowbreak{}o\allowbreak{}u\allowbreak{}n\allowbreak{}t\allowbreak{}e\allowbreak{}r\allowbreak{}D\allowbreak{}e\allowbreak{}m\allowbreak{}o\allowbreak{}B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k}, making the preview group demonstrate an interactive block first.

Static and descriptive block previews remain available below it. The prior navigation fix that lets focus move from the first preview child back to the \texttt{B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{} \allowbreak{}P\allowbreak{}r\allowbreak{}e\allowbreak{}v\allowbreak{}i\allowbreak{}e\allowbreak{}w} parent row must not regress.

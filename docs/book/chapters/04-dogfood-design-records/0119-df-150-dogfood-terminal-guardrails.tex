\section{Sponsor Human}\label{record-119-sponsor-human}

A learner launching DOGFOOD from a terminal who needs to know that it will take over the screen and how to leave it.

\section{Sponsor Agent}\label{record-119-sponsor-agent}

A docs-surface verification agent that can prove the DOGFOOD entrypoint behaves deterministically in TTY and non-TTY contexts.

\section{Hill}\label{record-119-hill}

DOGFOOD announces its full-screen behavior, prints explicit quit controls, and refuses to launch through non-interactive stdin/stdout paths that cannot host the TUI.

\section{Scope}\label{record-119-scope}

\begin{itemize}
\tightlist
\item
  Add a terminal readiness helper for the DOGFOOD entrypoint.
\item
  Require both stdin and stdout to be TTYs before launching DOGFOOD.
\item
  Print a short full-screen notice and exit controls before \texttt{r\allowbreak{}u\allowbreak{}n\allowbreak{}(\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{})}.
\item
  Point scripted callers to the existing smoke command instead of failing silently through a pipe or redirected output.
\item
  Cover the guard in docs preview tests.
\end{itemize}

\section{Playback Questions}\label{record-119-playback-questions}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Does DOGFOOD tell the user it is about to launch a full-screen TUI?
\item
  Are the quit controls visible before terminal takeover?
\item
  Does a non-TTY stdin or stdout path fail with a useful message?
\item
  Does the message direct automation to the smoke command instead?
\end{enumerate}

\section{Accessibility / Assistive Reading Posture}\label{record-119-accessibility-assistive-reading-posture}

The warning is plain text on stderr before alt-screen rendering, so screen readers and logs can capture it without needing the TUI frame.

\section{Localization / Directionality Posture}\label{record-119-localization-directionality-posture}

This launch warning is host-entrypoint English text in this cycle.

\section{Agent Inspectability / Explainability Posture}\label{record-119-agent-inspectability-explainability-posture}

The readiness helper is a pure function over \texttt{c\allowbreak{}t\allowbreak{}x\allowbreak{}.\allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{}t\allowbreak{}i\allowbreak{}m\allowbreak{}e}, so tests can assert TTY and non-TTY behavior without spawning a terminal.

\section{Linked Invariants}\label{record-119-linked-invariants}

\begin{itemize}
\tightlist
\item
  Full-screen apps should declare terminal takeover before entering the app.
\item
  Non-interactive execution should point to scripted verification paths.
\end{itemize}

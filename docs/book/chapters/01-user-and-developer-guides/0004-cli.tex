\section{Published Binaries}\label{record-004-published-binaries}

\subsection{\texorpdfstring{\texttt{c\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}t\allowbreak{}e\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}t\allowbreak{}u\allowbreak{}i\allowbreak{}-\allowbreak{}a\allowbreak{}p\allowbreak{}p}}{}}\label{record-004-create-bijou-tui-app}

Scaffold a new high-fidelity TUI workspace.

\begin{CodeBlock}
npm create bijou-tui-app@latest my-app
\end{CodeBlock}

\subsection{\texorpdfstring{\texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}m\allowbreak{}c\allowbreak{}p}}{}}\label{record-004-bijou-mcp}

Run the MCP server exposing Bijou rendering tools over stdio.

\begin{CodeBlock}
node node_modules/@flyingrobots/bijou-mcp/bin/bijou-mcp.js
\end{CodeBlock}

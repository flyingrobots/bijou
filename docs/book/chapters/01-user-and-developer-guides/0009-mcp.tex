\section{What Ships Today}\label{record-009-what-ships-today}

Bijou currently ships one MCP package:

\begin{itemize}
\tightlist
\item
  \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/packages/bijou-mcp/README.md}{\texttt{@\allowbreak{}f\allowbreak{}l\allowbreak{}y\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}r\allowbreak{}o\allowbreak{}b\allowbreak{}o\allowbreak{}t\allowbreak{}s\allowbreak{}/\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}m\allowbreak{}c\allowbreak{}p}}
\end{itemize}

It exposes Bijou terminal components as rendering tools over stdio so an MCP client can ask for structured terminal output without needing a live TTY.

\section{What It Is Good For}\label{record-009-what-it-is-good-for}

Use the MCP server when you want:

\begin{itemize}
\tightlist
\item
  box-drawn or structured terminal output inside a chat or agent context
\item
  Unicode-rich output without ANSI escape codes
\item
  component rendering as a tool surface rather than as a fullscreen runtime
\end{itemize}

\section{What It Is Not}\label{record-009-what-it-is-not}

The MCP package is not the fullscreen app runtime.

It does not own:

\begin{itemize}
\tightlist
\item
  \texttt{c\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}t\allowbreak{}e\allowbreak{}F\allowbreak{}r\allowbreak{}a\allowbreak{}m\allowbreak{}e\allowbreak{}d\allowbreak{}A\allowbreak{}p\allowbreak{}p\allowbreak{}(\allowbreak{})}
\item
  shell behavior, pane focus, help, settings, notifications, or quit flow
\item
  animation, motion, diffed terminal rendering, or interactive input routing
\end{itemize}

For those, use the normal package/runtime docs instead:

\begin{itemize}
\tightlist
\item
  \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/packages/bijou-tui/GUIDE.md}{packages/bijou-tui/GUIDE.md}
\item
  \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/packages/bijou-tui/ADVANCED_GUIDE.md}{packages/bijou-tui/ADVANCED\_GUIDE.md}

\section{Tool Families}\label{record-009-tool-families}

The current tool surface is grouped around:

\begin{itemize}
\tightlist
\item
  data and structure: tables, trees, DAGs, enumerated lists
\item
  containers and layout: boxes, header boxes, separators, constrain
\item
  feedback and status: alerts, progress, stepper, timeline, logs, badges
\item
  navigation: tabs, breadcrumb, paginator
\item
  rich panels: explainability, inspector, accordion
\item
  utility: keyboard indicators, hyperlinks, skeletons
\end{itemize}

For the exact tool list and examples, use the package README.

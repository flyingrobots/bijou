\section{Buffered Protocols}\label{record-003-buffered-protocols}

When Bijou buffers commands, events, or cross-boundary actions, those buffers should carry plain facts rather than executable behavior. The execution owner stays outside the buffer, which keeps queued state inspectable, replayable, and testable.

Use \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/invariants/buffer-holds-facts.md}{The Buffer Holds Facts} as the canonical invariant for that rule.

\section{Interaction Profiles}\label{record-003-interaction-profiles}

Bijou adapts its rendering behavior based on the detected output mode: - \textbf{\texttt{i\allowbreak{}n\allowbreak{}t\allowbreak{}e\allowbreak{}r\allowbreak{}a\allowbreak{}c\allowbreak{}t\allowbreak{}i\allowbreak{}v\allowbreak{}e}}: Full TEA loop, motion, and shell chrome. - \textbf{\texttt{s\allowbreak{}t\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}c}}: Single-frame render (e.g., CI logs). - \textbf{\texttt{p\allowbreak{}i\allowbreak{}p\allowbreak{}e}}: Plain-text fallback; no colors or complex layout. - \textbf{\texttt{a\allowbreak{}c\allowbreak{}c\allowbreak{}e\allowbreak{}s\allowbreak{}s\allowbreak{}i\allowbreak{}b\allowbreak{}l\allowbreak{}e}}: Linearized output for screen-readers.

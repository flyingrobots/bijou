This is the short architecture signpost for the docs surface.

Bijou is a nine-package monorepo for terminal software in TypeScript. The root \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/ARCHITECTURE.md}{ARCHITECTURE.md} is the main entrypoint, but DOGFOOD and the docs lane still need a repo-owned summary here.

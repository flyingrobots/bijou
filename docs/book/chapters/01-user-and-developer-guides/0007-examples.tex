\noindent{\footnotesize\color{BookMuted}\path{docs/EXAMPLES.md}\par}\smallskip

This file is no longer a giant per-example status ledger.

\section{Cut Later}\label{record-007-cut-later}

An example becomes a retirement candidate only when all of the following are true:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  DOGFOOD or another canonical scenario now teaches the same decision clearly.
\item
  No migration guide or package README still points to the example.
\item
  It is not carrying unique smoke or regression value.
\item
  It is not the clearest isolated proof of a public API seam.
\end{enumerate}

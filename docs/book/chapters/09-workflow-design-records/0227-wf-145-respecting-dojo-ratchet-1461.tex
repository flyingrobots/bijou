\section{Scope}\label{record-227-scope}

\begin{itemize}
\tightlist
\item
  Replace unsafe assertions, unused parameters, fake async commands, unchecked dynamic reads, and implicit interpolation with typed helpers, checked reads, explicit formatting, or narrowed runtime guards.
\item
  Preserve app-frame message contracts, example smoke orchestration, wall-time benchmark output, recorder behavior, and public TUI command types.
\item
  Lower ratchet artifacts only after live counts prove the reduction.
\end{itemize}

\section{Non-Goals}\label{record-227-non-goals}

\begin{itemize}
\tightlist
\item
  ESLint rules, Code Dojo thresholds, hooks, and CI policy must not weaken.
\item
  File/context, mock-ban, and code-size ceilings must not rise.
\item
  DOGFOOD raw visible-copy cleanup is out of scope for this slice unless it is deliberately chosen as the primary goalpost.
\item
  Exception churn cannot stand in for real cleanup.
\end{itemize}

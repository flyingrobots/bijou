\section{Hill}\label{record-201-hill}

The public \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} smoke contract now belongs to DOGFOOD.

The workspace scripts, release-readiness gauntlet, CI workflow, release-dry-run workflow, publish workflow, and release docs all agree that DOGFOOD is the release-facing smoke surface.

\section{Why this cycle exists}\label{record-201-why-this-cycle-exists}

\href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/design/DF-025-make-dogfood-the-only-human-facing-docs-surface.md}{DF-025} made the repo posture sharp: DOGFOOD, not \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/}, is the only human-facing docs surface for \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}.

But the release contract was still lying:

\begin{itemize}
\tightlist
\item
  \texttt{p\allowbreak{}a\allowbreak{}c\allowbreak{}k\allowbreak{}a\allowbreak{}g\allowbreak{}e\allowbreak{}.\allowbreak{}j\allowbreak{}s\allowbreak{}o\allowbreak{}n} still exposed \texttt{s\allowbreak{}m\allowbreak{}o\allowbreak{}k\allowbreak{}e\allowbreak{}:\allowbreak{}e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}:\allowbreak{}*} as the main smoke family
\item
  \texttt{r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}:\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}d\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}s\allowbreak{}s} still ran \texttt{s\allowbreak{}m\allowbreak{}o\allowbreak{}k\allowbreak{}e\allowbreak{}:\allowbreak{}e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}:\allowbreak{}a\allowbreak{}l\allowbreak{}l}
\item
  CI, release dry-runs, and publish verification still fanned out the old examples lanes
\item
  repo docs still talked about moving smoke to DOGFOOD as future work
\end{itemize}

That meant the repo could teach one surface while releasing against another.

\section{Decision}\label{record-201-decision}

\texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} release smoke belongs to DOGFOOD, not the broad \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/} tree.

Bijou should therefore:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  expose DOGFOOD smoke as the public smoke family
\item
  run DOGFOOD smoke in local release readiness
\item
  fan DOGFOOD smoke out in CI and release workflows
\item
  describe example smoke as secondary/internal rather than release canonical
\end{enumerate}

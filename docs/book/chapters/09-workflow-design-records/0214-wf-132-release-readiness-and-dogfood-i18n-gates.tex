\section{Hill}\label{record-214-hill}

Before \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} is cut, release readiness should be inspectable as a milestone-specific report and DOGFOOD i18n debt should cover newly added docs modules by default.

\section{Problem}\label{record-214-problem}

The repo already has \texttt{n\allowbreak{}p\allowbreak{}m\allowbreak{} \allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{} \allowbreak{}r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}:\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}d\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}s\allowbreak{}s}, but the command is mostly a validation gauntlet. It does not produce a milestone-aware readiness report that proves tracker closure, WIP-label cleanup, release-document posture, and package smoke coverage before a release tag.

The DOGFOOD i18n debt ratchet also depends on a hand-maintained source list. New \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}*\allowbreak{}*\allowbreak{}/\allowbreak{}*\allowbreak{}.\allowbreak{}t\allowbreak{}s} modules can introduce visible strings without participating in the debt baseline.

\section{Scope}\label{record-214-scope}

\begin{itemize}
\tightlist
\item
  Keep \texttt{r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}:\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}d\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}s\allowbreak{}s} as the single release readiness command.
\item
  Add an optional milestone report mode that can be run before tagging, for example \texttt{n\allowbreak{}p\allowbreak{}m\allowbreak{} \allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{} \allowbreak{}r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}:\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}d\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}s\allowbreak{}s\allowbreak{} \allowbreak{}-\allowbreak{}-\allowbreak{} \allowbreak{}-\allowbreak{}-\allowbreak{}m\allowbreak{}i\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}t\allowbreak{}o\allowbreak{}n\allowbreak{}e\allowbreak{} \allowbreak{}v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}.
\item
  Classify tracker, docs, release-packet, and package-smoke readiness using deterministic fixture-testable data.
\item
  Discover DOGFOOD TypeScript debt sources from \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}*\allowbreak{}*\allowbreak{}/\allowbreak{}*\allowbreak{}.\allowbreak{}t\allowbreak{}s} by default, with documented exclusions for tooling-only files.
\item
  Preserve per-surface i18n debt counts so ratchet output stays actionable.
\end{itemize}

\section{Non-Goals}\label{record-214-non-goals}

\begin{itemize}
\tightlist
\item
  Do not move broad V8/V9 product work into \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}.
\item
  Do not require GitHub access for the default no-argument local gauntlet.
\item
  Do not replace the GitHub release dry-run workflow; the local report should point to the existing workflow boundary.
\item
  Do not burn down the current DOGFOOD raw-string debt in this cycle.
\end{itemize}

\section{Accessibility / Assistive Posture}\label{record-214-accessibility-assistive-posture}

No runtime UI accessibility behavior changes. The new readiness report is plain text plus a Markdown table so it can be copied into release PRs and read by terminal or screen-reader workflows.

\section{Localization / Directionality Posture}\label{record-214-localization-directionality-posture}

\#312 directly strengthens localization guardrails. It does not localize existing raw DOGFOOD copy; it makes the current raw-string debt baseline honest across newly discovered DOGFOOD modules.

\section{Agent Inspectability / Explainability Posture}\label{record-214-agent-inspectability-explainability-posture}

The release-readiness report classifies each gate as pass/fail with a concise summary. The i18n debt scanner continues to report counts by source surface so agents can identify which DOGFOOD module moved the ratchet.

\section{Linked Invariants}\label{record-214-linked-invariants}

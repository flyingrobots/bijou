\section{Implementation Notes}\label{record-238-implementation-notes}

WF-156 removes \texttt{5\allowbreak{}3} live ESLint findings, lowering the ESLint baseline from \texttt{2\allowbreak{}1\allowbreak{}5} to \texttt{1\allowbreak{}6\allowbreak{}2} and the aggregate Code Dojo debt from \texttt{6\allowbreak{}2\allowbreak{}3} to \texttt{5\allowbreak{}7\allowbreak{}0}.

Touched cleanup clusters:

\begin{itemize}
\tightlist
\item
  TUI runtime, app-frame test support, notifications, browsable list, DAG pane, and string layout helpers.
\item
  Core block-tree rendering, grapheme sanitization, and timer spoken formatting.
\item
  Create-app CLI package parsing and npm pack output parsing.
\item
  Release readiness tracker parsing, release metadata tag handling, and smoke canary manifest/npm-pack/env handling.
\end{itemize}

Per the operator's temporary waiver for touched-file size ratchets during this slice, existing file/context and code-size entries for touched legacy-large files were refreshed. The counted file/context and code-size totals do not grow.

Known remaining top ESLint clusters after this pass include i18n runtime, PR review status, i18n filesystem/localization helpers, MCP docs tooling, and small TUI/core tests. The next goalpost target is \texttt{5\allowbreak{}2\allowbreak{}0} aggregate violations or lower.

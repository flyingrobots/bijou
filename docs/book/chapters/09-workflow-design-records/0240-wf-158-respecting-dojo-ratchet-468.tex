\section{Implementation Notes}\label{record-240-implementation-notes}

WF-158 removes \texttt{5\allowbreak{}3} live type-aware ESLint findings, lowering the ESLint baseline from \texttt{1\allowbreak{}1\allowbreak{}0} to \texttt{5\allowbreak{}7} and the aggregate Code Dojo ceiling from \texttt{5\allowbreak{}1\allowbreak{}8} to \texttt{4\allowbreak{}6\allowbreak{}5}.

Cleanup clusters:

\begin{itemize}
\tightlist
\item
  Core forms and tests: preserve empty-answer default semantics while replacing unsafe fallback chains, add explicit numeric formatting in fuzz fixtures, and remove control-character regex literals from prompt/progress tests.
\item
  DOGFOOD and cycle tests: replace visible frame-text fallbacks with nullish checks, remove unnecessary conversions, and keep rendered text assertions behaviorally equivalent.
\item
  Bench and smoke helpers: type GC sample arrays, make JSONL parsing return \texttt{u\allowbreak{}n\allowbreak{}k\allowbreak{}n\allowbreak{}o\allowbreak{}w\allowbreak{}n}, document intentional no-op sinks, and remove needless async wrappers.
\item
  TUI helpers: replace non-null assertions with checked reads in command palette, file picker, panel focus, input stack, status bar, cell glyph, CSS parser, and app-frame layout traversal.
\item
  Core components: remove unnecessary fallbacks from already-required string inputs, unify DAG overloads, and keep runtime viewport overlay typing direct.
\end{itemize}

Per the operator's temporary waiver for touched-file size ratchets, existing file/context entries for touched legacy-large files were refreshed to their current measured line/byte counts. No new counted file/context, mock-ban, or code-size entries were added.

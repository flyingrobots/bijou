\section{Scope}\label{record-232-scope}

\begin{itemize}
\tightlist
\item
  Select a focused cleanup slice from current ESLint or Code Dojo offenders.
\item
  Remove at least \texttt{5\allowbreak{}0} counted violations with real fixes.
\item
  Prefer real type, data-shape, and control-flow fixes over suppressions or cosmetic baseline churn.
\item
  Keep touched file/context, mock-ban, code-size, and DOGFOOD localization ratchets flat or lower.
\item
  Ratchet stale baseline entries down or out when touched files fall below thresholds.
\item
  Update the Code Dojo exception ledger, ESLint baseline, package ceiling, and changelog with the landed count.
\end{itemize}

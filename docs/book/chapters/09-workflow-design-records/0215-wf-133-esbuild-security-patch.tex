\section{Hill}\label{record-215-hill}

Before \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}2\allowbreak{}.\allowbreak{}0} ships, Bijou's development dependency graph should resolve the patched \texttt{e\allowbreak{}s\allowbreak{}b\allowbreak{}u\allowbreak{}i\allowbreak{}l\allowbreak{}d\allowbreak{}@\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}1} release so GitHub and npm audit no longer report the known \texttt{e\allowbreak{}s\allowbreak{}b\allowbreak{}u\allowbreak{}i\allowbreak{}l\allowbreak{}d\allowbreak{}@\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}0} security advisories.

\section{Problem}\label{record-215-problem}

\texttt{n\allowbreak{}p\allowbreak{}m\allowbreak{} \allowbreak{}a\allowbreak{}u\allowbreak{}d\allowbreak{}i\allowbreak{}t} reports the lockfile-resolved \texttt{e\allowbreak{}s\allowbreak{}b\allowbreak{}u\allowbreak{}i\allowbreak{}l\allowbreak{}d\allowbreak{}@\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}0} package against two GitHub advisories:

\begin{itemize}
\tightlist
\item
  \texttt{G\allowbreak{}H\allowbreak{}S\allowbreak{}A\allowbreak{}-\allowbreak{}g\allowbreak{}v\allowbreak{}7\allowbreak{}w\allowbreak{}-\allowbreak{}r\allowbreak{}q\allowbreak{}v\allowbreak{}m\allowbreak{}-\allowbreak{}q\allowbreak{}j\allowbreak{}h\allowbreak{}r} (\texttt{h\allowbreak{}i\allowbreak{}g\allowbreak{}h}), patched in \texttt{0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}1}.
\item
  \texttt{G\allowbreak{}H\allowbreak{}S\allowbreak{}A\allowbreak{}-\allowbreak{}g\allowbreak{}7\allowbreak{}r\allowbreak{}4\allowbreak{}-\allowbreak{}m\allowbreak{}6\allowbreak{}w\allowbreak{}7\allowbreak{}-\allowbreak{}q\allowbreak{}q\allowbreak{}q\allowbreak{}r} (\texttt{l\allowbreak{}o\allowbreak{}w}), patched in \texttt{0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}1}.
\end{itemize}

The package is present through development tooling, not Bijou runtime API:

\begin{itemize}
\tightlist

  \texttt{t\allowbreak{}s\allowbreak{}x\allowbreak{}@\allowbreak{}4\allowbreak{}.\allowbreak{}2\allowbreak{}2\allowbreak{}.\allowbreak{}4} accepts \texttt{e\allowbreak{}s\allowbreak{}b\allowbreak{}u\allowbreak{}i\allowbreak{}l\allowbreak{}d\allowbreak{}@\allowbreak{}\textasciitilde{}\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}0}.
\item
  \texttt{v\allowbreak{}i\allowbreak{}t\allowbreak{}e\allowbreak{}s\allowbreak{}t\allowbreak{}@\allowbreak{}4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}8} pulls \texttt{v\allowbreak{}i\allowbreak{}t\allowbreak{}e\allowbreak{}@\allowbreak{}8\allowbreak{}.\allowbreak{}0\allowbreak{}.\allowbreak{}1\allowbreak{}6}, whose optional peer accepts \texttt{e\allowbreak{}s\allowbreak{}b\allowbreak{}u\allowbreak{}i\allowbreak{}l\allowbreak{}d\allowbreak{}@\allowbreak{}\textasciicircum{}\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}7\allowbreak{}.\allowbreak{}0\allowbreak{} \allowbreak{}|\allowbreak{}|\allowbreak{} \allowbreak{}\textasciicircum{}\allowbreak{}0\allowbreak{}.\allowbreak{}2\allowbreak{}8\allowbreak{}.\allowbreak{}0}.

\section{Scope}\label{record-215-scope}

\begin{itemize}
\tightlist

\end{itemize}

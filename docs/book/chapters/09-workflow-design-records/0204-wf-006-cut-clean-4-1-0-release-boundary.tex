\section{Why this cycle exists}\label{record-204-why-this-cycle-exists}

\href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/design/WF-004-shape-the-next-release.md}{WF-004} chose \texttt{4\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0}, and \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/design/WF-005-close-4-1-0-i18n-publish-surface-gap.md}{WF-005} closed the i18n publish-surface gap.

But the short-form release surfaces were still drifting:

\begin{itemize}
\tightlist
\item
  the root \texttt{R\allowbreak{}E\allowbreak{}A\allowbreak{}D\allowbreak{}M\allowbreak{}E\allowbreak{}.\allowbreak{}m\allowbreak{}d} still led with a \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}0\allowbreak{}.\allowbreak{}0} ``What's New'' section
\item
  \texttt{C\allowbreak{}H\allowbreak{}A\allowbreak{}N\allowbreak{}G\allowbreak{}E\allowbreak{}L\allowbreak{}O\allowbreak{}G\allowbreak{}.\allowbreak{}m\allowbreak{}d} still treated \texttt{[\allowbreak{}U\allowbreak{}n\allowbreak{}r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}d\allowbreak{}]} as a vague bucket instead of an explicit \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}0\allowbreak{}.\allowbreak{}0\allowbreak{}.\allowbreak{}.\allowbreak{}H\allowbreak{}E\allowbreak{}A\allowbreak{}D} release slice
\item
  the compare links still implied \texttt{v\allowbreak{}3\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} was the previous release
\item
  \texttt{v\allowbreak{}4\allowbreak{}.\allowbreak{}0\allowbreak{}.\allowbreak{}0} itself never got a dedicated changelog section
\end{itemize}

That meant the repo had long-form release docs but still lacked an honest short-form release cut.

\def\labelenumi{\arabic{enumi}.}

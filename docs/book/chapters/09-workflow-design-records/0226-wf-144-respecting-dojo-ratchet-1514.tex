\section{Scope}\label{record-226-scope}

\begin{itemize}
\tightlist
\item
  Replace non-null assertions, unsafe assertions, \texttt{a\allowbreak{}n\allowbreak{}y} escapes, unchecked dynamic reads, and implicit interpolation with typed helpers, checked reads, explicit formatting, or narrowed runtime guards.
\item
  Prefer local helper extraction only when it removes repeated unsafe patterns without increasing touched file/context debt.
\item
  Preserve TUI app-frame rendering, scoped message wrapping, recorder behavior, smoke example orchestration, and bench runner output.
\item
  Lower ratchet artifacts only after live counts prove the reduction.
\end{itemize}

\section{Non-Goals}\label{record-226-non-goals}

\begin{itemize}
\tightlist
\item
  ESLint rules, Code Dojo thresholds, hooks, and CI policy must not weaken.
\item
  File/context, mock-ban, and code-size ceilings must not rise.
\item
  DOGFOOD docs raw-string cleanup is out of scope for this slice unless it is deliberately chosen as the primary goalpost.
\item
  Exception churn cannot stand in for real cleanup.
\end{itemize}

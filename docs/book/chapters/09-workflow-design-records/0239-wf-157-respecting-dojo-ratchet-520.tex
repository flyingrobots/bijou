\section{Implementation Notes}\label{record-239-implementation-notes}

WF-157 removes \texttt{5\allowbreak{}2} live type-aware ESLint findings, lowering the ESLint baseline from \texttt{1\allowbreak{}6\allowbreak{}2} to \texttt{1\allowbreak{}1\allowbreak{}0} and the aggregate Code Dojo ceiling from \texttt{5\allowbreak{}7\allowbreak{}0} to \texttt{5\allowbreak{}1\allowbreak{}8}.

Cleanup clusters:

\begin{itemize}
\tightlist
\item
  i18n runtime-adjacent boundaries: story protocol index guards, catalog filesystem parsing, authoring-tool record handling, and localized value clone/freeze validation.
\item
  MCP docs examples: replace docs-only renderer assertions with local JSON-shape coercion helpers for guided flow, preference list, and stats panel examples.
\item
  TUI/core tests and helpers: keybinding/action visibility checks, drawer invalid-input coverage, runtime support typing, subapp command mapping, binding-frame invalid input coverage, DOGFOOD block registry invalid-input and immutability checks, flex/pager numeric formatting, navigable-table repeat loops, notification row guards, motion reconciliation narrowing, and split-pane grapheme guards.
\item
  Examples: mark top-level app launches as intentionally floated with \texttt{v\allowbreak{}o\allowbreak{}i\allowbreak{}d}.
\end{itemize}

Per the operator's temporary waiver for touched-file size ratchets, existing file/context entries for touched legacy-large files were refreshed to their current measured line/byte counts. No new counted file/context, mock-ban, or code-size entries were added.

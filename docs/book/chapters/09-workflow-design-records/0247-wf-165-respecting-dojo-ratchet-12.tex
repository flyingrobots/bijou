\section{Decision Summary}\label{record-247-decision-summary}

Complete issue \href{https://github.com/flyingrobots/bijou/issues/480}{\#480} by removing all \texttt{2\allowbreak{}5} files that are counted in both the file/context and code-size ledgers. The combined \texttt{5\allowbreak{}0}-violation reduction lowers aggregate Code Dojo debt from \texttt{6\allowbreak{}2} to \texttt{1\allowbreak{}2} or lower.

Deliver the goalpost through bounded review tranches. Each tranche preserves public entrypoints as typed compatibility facades, proves that its extracted module family remains outside runtime import cycles, and lowers only the live ledger entries it actually removes.

\section{Hill}\label{record-247-hill}

The repository has \texttt{3\allowbreak{}7} file/context violations and \texttt{2\allowbreak{}5} code-size violations. All \texttt{2\allowbreak{}5} code-size offenders are also file/context offenders. Removing those double-counted roots behind stable facades therefore satisfies the next mandatory \texttt{5\allowbreak{}0}-violation goalpost without weakening a threshold, adding an exception, or changing public behavior.

\section{Scope}\label{record-247-scope}

\begin{itemize}
\tightlist
\item
  Bind the exact \texttt{2\allowbreak{}5} double-counted roots in deterministic cycle evidence.
\item
  Deliver those roots through bounded review tranches.
\item
  Start tranche A with the five smaller roots named in this design.
\item
  Preserve every selected public import path and export name.
\item
  Keep mutable module state inside one implementation module unless an explicit port makes cross-module ownership safe.
\item
  Keep overload declarations beside their implementation.
\item
  Preserve source-debt identity across extracted implementation parts.
\item
  Prove every changed split family remains absent from runtime import cycles.
\item
  Remove ledger entries only after the live size gates accept the facade and extracted modules.
\item
  Lower the package debt ceiling only to the measured live result.
\item
  Update the exception ledger, changelog, roadmap, bearing, and cycle evidence in every tranche.
\end{itemize}

\section{Decision Summary}\label{record-244-decision-summary}

Cut \texttt{1\allowbreak{}0\allowbreak{}0} counted Code Dojo debt items from the merged \texttt{2\allowbreak{}6\allowbreak{}2} baseline and land the next Respecting the Dojo checkpoint at \texttt{1\allowbreak{}6\allowbreak{}2} aggregate violations or lower.

\section{Hill}\label{record-244-hill}

WF-161 exhausted most of the low-risk oversized test/spec split pool. The repo still carries structural debt in file/context and code-size ledgers, so this cycle has to combine remaining deterministic test decomposition with production, tooling, and example module extraction.

The goal is not cosmetic movement. The resulting ledgers must describe less debt because large files were split into smaller, coherent modules without weakening public behavior, tests, or standards.

\section{Implementation Strategy}\label{record-244-implementation-strategy}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Finish the deterministic test split pool.}

  \begin{itemize}
  \tightlist
  \item
    Split the remaining over-threshold test/spec files into focused threshold-sized specs.
  \item
    Preserve all assertions and snapshots.
  \item
    Prefer semantic describe-group boundaries over arbitrary line cuts.
  \end{itemize}
\item
  \textbf{Extract high-yield code-size modules.}

  \begin{itemize}
  \tightlist
  \item
    Target modules where one extraction removes both a file/context entry and a code-size entry.
  \item
    Keep stable public files as facades that re-export or delegate to focused internals.
  \item
    Avoid broad rewrites inside domain logic unless tests pin the behavior.
  \end{itemize}
\item
  \textbf{Extract file/context-only modules when needed.}

  \begin{itemize}
  \tightlist
  \item
    Target self-contained data, fixtures, option tables, test support helpers, parser/render helper clusters, and CLI workflow helpers.
  \item
    Keep each new file below \texttt{1\allowbreak{}5\allowbreak{}0} lines and \texttt{1\allowbreak{}2\allowbreak{},\allowbreak{}0\allowbreak{}0\allowbreak{}0} bytes.
  \end{itemize}
\item
  \textbf{Ratcheting and proof.}

  \begin{itemize}
  \tightlist
  \item
    Regenerate the file/context baseline from live files.
  \item
    Remove code-size entries only when live files are below the ratchet limit or have been replaced by smaller modules.
  \item
    Lower the aggregate debt ceiling to \texttt{1\allowbreak{}6\allowbreak{}2} or lower.
  \end{itemize}
\end{enumerate}

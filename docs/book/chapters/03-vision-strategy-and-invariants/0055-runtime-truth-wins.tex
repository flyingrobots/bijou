When runtime facts disagree with comments, type-only claims, or editor comfort, runtime truth wins.

Implications:

\begin{itemize}
\tightlist
\item
  trusted values must be established through construction, parsing, or validation
\item
  a type annotation alone does not make data safe
\item
  docs and JSDoc must describe runtime behavior that actually exists
\item
  if the runtime and the types disagree, fix the mismatch instead of hand-waving it away
\end{itemize}

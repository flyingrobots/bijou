Schemas and parsers should reject malformed input at system edges, then hand trusted values to runtime-backed domain forms.

Implications:

\begin{itemize}
\tightlist
\item
  \texttt{u\allowbreak{}n\allowbreak{}k\allowbreak{}n\allowbreak{}o\allowbreak{}w\allowbreak{}n} belongs at the edge, not deep in the core
\item
  decoding and validation should happen before domain logic starts
\item
  core behavior should not keep re-validating already trusted values
\item
  plain decoded objects are not the final domain model
\end{itemize}

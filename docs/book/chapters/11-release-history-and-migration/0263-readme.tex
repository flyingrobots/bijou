Long-form release documentation lives under \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}s\allowbreak{}/}.

Use this directory for material that is more explanatory than \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/CHANGELOG.md}{\texttt{C\allowbreak{}H\allowbreak{}A\allowbreak{}N\allowbreak{}G\allowbreak{}E\allowbreak{}L\allowbreak{}O\allowbreak{}G\allowbreak{}.\allowbreak{}m\allowbreak{}d}}:

\begin{itemize}
\tightlist
\item
  release overviews and ``what changed'' walkthroughs
\item
  migration guides for existing users
\item
  version-specific notes that should stay readable after the release is no longer ``current''
\end{itemize}

\section{Working Rule}\label{record-263-working-rule}

While a release version is still undecided, draft the long-form docs in \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}r\allowbreak{}e\allowbreak{}l\allowbreak{}e\allowbreak{}a\allowbreak{}s\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}n\allowbreak{}e\allowbreak{}x\allowbreak{}t\allowbreak{}/}.

\section{Bench Scenario API Change (Internal)}\label{record-267-bench-scenario-api-change-internal}

If you have custom benchmark scenarios, the \texttt{s\allowbreak{}e\allowbreak{}t\allowbreak{}u\allowbreak{}p\allowbreak{}(\allowbreak{})} function signature now accepts optional \texttt{c\allowbreak{}o\allowbreak{}l\allowbreak{}u\allowbreak{}m\allowbreak{}n\allowbreak{}s} and \texttt{r\allowbreak{}o\allowbreak{}w\allowbreak{}s} positional arguments after \texttt{c\allowbreak{}t\allowbreak{}x}: \texttt{s\allowbreak{}e\allowbreak{}t\allowbreak{}u\allowbreak{}p\allowbreak{}(\allowbreak{}c\allowbreak{}t\allowbreak{}x\allowbreak{}?\allowbreak{},\allowbreak{} \allowbreak{}c\allowbreak{}o\allowbreak{}l\allowbreak{}u\allowbreak{}m\allowbreak{}n\allowbreak{}s\allowbreak{}?\allowbreak{},\allowbreak{} \allowbreak{}r\allowbreak{}o\allowbreak{}w\allowbreak{}s\allowbreak{}?\allowbreak{})}. Existing scenarios that ignore these arguments continue to work unchanged.

\chapter{Design Records}\label{record-259}

\noindent{\footnotesize\color{BookMuted}\path{docs/design/README.md}\par}\smallskip

This directory preserves technical decisions and implementation evidence. Current scope and release order live in GitHub issues and milestones; Linear is the chosen execution tracker, pending connection and workspace/team selection.

Write a design record when a change needs a durable technical decision. Name the problem, scope, non-goals, observable contract, acceptance checks, prerequisites, and validation plan. Link the work item and PR. Update the record with actual results when the change lands.

Existing cycle identifiers and templates preserve historical provenance. New work does not require METHOD ceremonies, sponsor fields, a cycle branch name, or an advance shaping commit. Keep existing filenames stable for linked evidence.

The complete design corpus is also available as the \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/book/README.md}{Design Book}, with LaTeX source, a PDF edition, TikZ diagrams, and actual DOGFOOD cell specimens.

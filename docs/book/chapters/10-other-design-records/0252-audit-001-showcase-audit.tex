\section{Why this cycle exists}\label{record-252-why-this-cycle-exists}

The Showcase app is the most visible ``complex'' implementation of Bijou. If it contains anti-patterns (e.g., hardcoded colors, loose typing, or mixed architectural concerns), it will mislead developers into adopting those same bad habits.

As the \textbf{EXPERT Bijou BigBro}, I must audit this app to: - Identify and backlog ``sludge'' for correction. - Propose refactors that align with the \textbf{Hexagonal} and \textbf{TEA} pillars. - Ensure it serves as a ``Humane'' reference for others.

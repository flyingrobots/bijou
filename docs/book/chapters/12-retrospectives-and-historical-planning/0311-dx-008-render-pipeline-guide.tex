\section{Problem}\label{record-311-problem}

The render pipeline (the illustrated sequence below) is a powerful extension point but has zero documentation beyond type definitions. \texttt{c\allowbreak{}o\allowbreak{}n\allowbreak{}f\allowbreak{}i\allowbreak{}g\allowbreak{}u\allowbreak{}r\allowbreak{}e\allowbreak{}P\allowbreak{}i\allowbreak{}p\allowbreak{}e\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}e} appears in RunOptions but there is no guide showing how to write middleware, what RenderState fields are available, or how stages interact.

The perf-gradient demo proved this gap --- we could not instrument the pipeline from outside to measure per-stage timing.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  The five render stages and what each does
\item
  How to write a custom RenderMiddleware (worked example)
\item
  RenderState fields and their lifecycle
\item
  How configurePipeline interacts with default stages
\item
  Limitations (sync-only, no stage replacement, no timing hooks)

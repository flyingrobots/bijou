\section{Idea}\label{record-288-idea}

Add a ``Post-Process'' middleware to \texttt{@\allowbreak{}f\allowbreak{}l\allowbreak{}y\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}r\allowbreak{}o\allowbreak{}b\allowbreak{}o\allowbreak{}t\allowbreak{}s\allowbreak{}/\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}t\allowbreak{}u\allowbreak{}i}'s render pipeline that operates directly on the final byte-buffer before it is diffed and emitted. This middleware could simulate:

\begin{itemize}
\tightlist
\item
  CRT scanlines (alternating row brightness/dimming)
\item
  Scanline flicker (subtle per-frame variation)
\item
  Signal static / noise (random cell or byte corruption)
\item
  ``Vignette'' effects (darkening edges of the terminal)
\end{itemize}

\section{Why}\label{record-288-why}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Expressivity}: It pushes the ``high-fidelity'' aesthetic to its limit, giving Bijou apps a distinct feel that is both professional and nostalgic.
\item
  \textbf{Low-Allocation Performance}: Since the pipeline is byte-packed, these effects can be implemented using zero-allocation loops on typed arrays.
\item
  \textbf{Product Differentiation}: It shows that the terminal can be an expressive visual medium, not just a static character grid.
\end{enumerate}

\section{Effort}\label{record-288-effort}

Medium --- requires adding the middleware and a set of byte-manipulation shaders for common effects.

\section{Completed (2026-04-14)}\label{record-288-completed-2026-04-14}

The post-process path now ships as a reusable \texttt{s\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e\allowbreak{}S\allowbreak{}h\allowbreak{}a\allowbreak{}d\allowbreak{}e\allowbreak{}r\allowbreak{}F\allowbreak{}i\allowbreak{}l\allowbreak{}t\allowbreak{}e\allowbreak{}r\allowbreak{}(\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{})} middleware for the render pipeline's \texttt{P\allowbreak{}o\allowbreak{}s\allowbreak{}t\allowbreak{}P\allowbreak{}r\allowbreak{}o\allowbreak{}c\allowbreak{}e\allowbreak{}s\allowbreak{}s} stage. Bijou TUI now exports built-in packed-surface shader passes for \texttt{s\allowbreak{}c\allowbreak{}a\allowbreak{}n\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}s\allowbreak{}(\allowbreak{})}, \texttt{f\allowbreak{}l\allowbreak{}i\allowbreak{}c\allowbreak{}k\allowbreak{}e\allowbreak{}r\allowbreak{}(\allowbreak{})}, \texttt{n\allowbreak{}o\allowbreak{}i\allowbreak{}s\allowbreak{}e\allowbreak{}(\allowbreak{})}, and \texttt{v\allowbreak{}i\allowbreak{}g\allowbreak{}n\allowbreak{}e\allowbreak{}t\allowbreak{}t\allowbreak{}e\allowbreak{}(\allowbreak{})}, along with regression coverage and a package-level \texttt{c\allowbreak{}o\allowbreak{}n\allowbreak{}f\allowbreak{}i\allowbreak{}g\allowbreak{}u\allowbreak{}r\allowbreak{}e\allowbreak{}P\allowbreak{}i\allowbreak{}p\allowbreak{}e\allowbreak{}l\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}(\allowbreak{})} example. Apps can now compose CRT-style or atmosphere-oriented post-process effects without forking the runtime or inventing a second render pipeline.

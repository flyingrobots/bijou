\noindent{\footnotesize\color{BookMuted}\path{docs/method/graveyard/legacy-backlog/README.md}\par}\smallskip

This directory is \textbf{not} the canonical live backlog anymore.

Bijou now keeps the live queue in \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/method/graveyard/method/backlog/README.md}{\texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}m\allowbreak{}e\allowbreak{}t\allowbreak{}h\allowbreak{}o\allowbreak{}d\allowbreak{}/\allowbreak{}b\allowbreak{}a\allowbreak{}c\allowbreak{}k\allowbreak{}l\allowbreak{}o\allowbreak{}g\allowbreak{}/}}. This tree remains only as:

\begin{itemize}
\tightlist
\item
  a historical archive of pre-METHOD backlog notes
\item
  a compatibility surface for old links in design docs, audits, tests, and release notes
\item
  a place where older shaped-release snapshots can remain legible without pretending to be current queue truth
\end{itemize}

\section{Rule}\label{record-386-rule}

Do \textbf{not} add new live backlog work here.

If a legacy note is still active, give it a canonical METHOD copy and continue the work there. Keep the legacy file only for historical provenance or compatibility.

Every legacy note in this archive now has a corresponding canonical METHOD placement under \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}m\allowbreak{}e\allowbreak{}t\allowbreak{}h\allowbreak{}o\allowbreak{}d\allowbreak{}/} so current work can be evaluated without treating this tree as the live queue.

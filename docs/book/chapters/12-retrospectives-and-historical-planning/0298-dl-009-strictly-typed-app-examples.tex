\section{Idea}\label{record-298-idea}

Many code examples in the repository's READMEs and GUIDEs currently use \texttt{A\allowbreak{}p\allowbreak{}p\allowbreak{}<\allowbreak{}a\allowbreak{}n\allowbreak{}y\allowbreak{},\allowbreak{} \allowbreak{}a\allowbreak{}n\allowbreak{}y\allowbreak{}>} or \texttt{M\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}l\allowbreak{} \allowbreak{}=\allowbreak{} \allowbreak{}a\allowbreak{}n\allowbreak{}y}. While concise, this masks the core TypeScript safety guarantees that make Bijou an ``industrial-grade'' engine.

Refactor all top-level documentation examples to use concrete \texttt{M\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}l} and \texttt{M\allowbreak{}s\allowbreak{}g} types. Ensure that the \texttt{i\allowbreak{}n\allowbreak{}i\allowbreak{}t}, \texttt{u\allowbreak{}p\allowbreak{}d\allowbreak{}a\allowbreak{}t\allowbreak{}e}, and \texttt{v\allowbreak{}i\allowbreak{}e\allowbreak{}w} functions are shown with their full generic context.

\section{Why}\label{record-298-why}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Safety}: Demonstrates the TEA loop's state-machine guarantees immediately to new users.
\item
  \textbf{Clarity}: Makes it clear how messages and models flow through the update cycle.
\item
  \textbf{Consistency}: Aligns the documentation with the ``Tests are the Spec'' and ``Runtime Truth Wins'' invariants.
\end{enumerate}

\section{Disposition}\label{record-408-disposition}

Legacy planning entrypoints now identify themselves honestly: ROADMAP is reference-only, docs/specs is a frozen legacy spec archive with an explicit migration rule, docs/strategy now has a directory index separating living doctrine from historical notes, and the older strategy notes that overlap newer signposts now point readers back to the canonical surfaces.

\section{Idea}\label{record-408-idea}

The new Legends/Cycles workflow is adopted, but older planning surfaces still exist:

\begin{itemize}
\tightlist
\item
  \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}R\allowbreak{}O\allowbreak{}A\allowbreak{}D\allowbreak{}M\allowbreak{}A\allowbreak{}P\allowbreak{}.\allowbreak{}m\allowbreak{}d}
\item
  \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}s\allowbreak{}p\allowbreak{}e\allowbreak{}c\allowbreak{}s\allowbreak{}/}
\item
  older \texttt{d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}s\allowbreak{}t\allowbreak{}r\allowbreak{}a\allowbreak{}t\allowbreak{}e\allowbreak{}g\allowbreak{}y\allowbreak{}/} notes that are not legend docs
\end{itemize}

This cycle would decide what gets:

\begin{itemize}
\tightlist
\item
  migrated
\item
  frozen
\item
  archived
\item
  rewritten as backlog/design docs
\end{itemize}

\section{Why}\label{record-408-why}

WF-001 intentionally adopted the new process without trying to convert the entire repo in one shot.

That was the right call, but it leaves migration debt behind.

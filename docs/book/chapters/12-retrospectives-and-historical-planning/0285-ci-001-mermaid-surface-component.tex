\section{Idea}\label{record-285-idea}

Since Bijou uses Mermaid for its documentation, wouldn't it be cool to render Mermaid diagrams directly in the TUI? This component would parse a (limited) subset of Mermaid (flowcharts and state diagrams) and render them to a \texttt{S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e} using Bijou's box-drawing and graph primitives.

\section{Why}\label{record-285-why}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Self-Documentation}: A TUI app can render its own architecture or cycle state without external tools.
\item
  \textbf{Data-Viz Maturity}: It pushes the ``geometric lawfulness'' of the terminal by showing that complex, logic-heavy graphs are native to the medium.
\item
  \textbf{Docs Synergy}: If DOGFOOD could render diagrams locally, it would complete the ``docs are the demo'' story.
\end{enumerate}

\section{Effort}\label{record-285-effort}

Large --- requires a simplified Mermaid parser and a spatial-layout engine to map diagrams to terminal cells.

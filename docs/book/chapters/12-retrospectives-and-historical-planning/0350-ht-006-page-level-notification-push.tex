\section{Problem}\label{record-350-problem}

Pages in \texttt{c\allowbreak{}r\allowbreak{}e\allowbreak{}a\allowbreak{}t\allowbreak{}e\allowbreak{}F\allowbreak{}r\allowbreak{}a\allowbreak{}m\allowbreak{}e\allowbreak{}d\allowbreak{}A\allowbreak{}p\allowbreak{}p} cannot push transient notifications. The \texttt{p\allowbreak{}u\allowbreak{}s\allowbreak{}h\allowbreak{}N\allowbreak{}o\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}i\allowbreak{}c\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n} function operates on \texttt{F\allowbreak{}r\allowbreak{}a\allowbreak{}m\allowbreak{}e\allowbreak{}M\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}l\allowbreak{}.\allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{}t\allowbreak{}i\allowbreak{}m\allowbreak{}e\allowbreak{}N\allowbreak{}o\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}i\allowbreak{}c\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n\allowbreak{}s}, but pages only return \texttt{[\allowbreak{}P\allowbreak{}a\allowbreak{}g\allowbreak{}e\allowbreak{}M\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}l\allowbreak{},\allowbreak{} \allowbreak{}C\allowbreak{}m\allowbreak{}d\allowbreak{}<\allowbreak{}M\allowbreak{}s\allowbreak{}g\allowbreak{}>\allowbreak{}[\allowbreak{}]\allowbreak{}]} --- they have no access to frame-level state.

Currently only the frame shell itself can push notifications (settings feedback, runtime issues). Page-level events like ``No more thoughts in this session'' have no way to surface as notifications.

\section{Proposal}\label{record-350-proposal}

Add a \texttt{p\allowbreak{}u\allowbreak{}s\allowbreak{}h\allowbreak{}-\allowbreak{}n\allowbreak{}o\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}i\allowbreak{}c\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n} FrameAction that pages can emit via a command:

\begin{CodeBlock}
// In page update:
return [model, [emitFrameAction({ type: 'push-notification', title: 'End of session', durationMs: 2000 })]];
\end{CodeBlock}

Or expose a \texttt{n\allowbreak{}o\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}y\allowbreak{}(\allowbreak{})} command helper:

\begin{CodeBlock}
import { notify } from '@flyingrobots/bijou-tui';
return [model, [notify({ title: 'End of session', variant: 'TOAST', durationMs: 2000 })]];
\end{CodeBlock}

\section{Workaround}\label{record-350-workaround}

Render the notice as a positioned overlay via \texttt{o\allowbreak{}v\allowbreak{}e\allowbreak{}r\allowbreak{}l\allowbreak{}a\allowbreak{}y\allowbreak{}F\allowbreak{}a\allowbreak{}c\allowbreak{}t\allowbreak{}o\allowbreak{}r\allowbreak{}y}, which has access to the page model.

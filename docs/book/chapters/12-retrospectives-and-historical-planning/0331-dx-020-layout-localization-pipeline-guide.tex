\section{Problem}\label{record-331-problem}

\begin{itemize}
\tightlist
\item
  localization vs painting
\item
  how offsets accumulate
\item
  when layout is recomputed
\item
  where retained-layout work would fit
\end{itemize}

The 2026-04-11 documentation audit called this out as a missing deep guide for advanced users and maintainers.

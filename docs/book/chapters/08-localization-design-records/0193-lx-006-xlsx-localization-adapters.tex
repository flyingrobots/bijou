\section{Why this cycle exists}\label{record-193-why-this-cycle-exists}

LX-005 made the exchange seam practical on disk through:

\begin{itemize}
\tightlist
\item
  CSV / TSV sheet files
\item
  JSON bundle files
\item
  workbook directories with a manifest
\end{itemize}

That still leaves a common real-world localization format uncovered:

\begin{itemize}
\tightlist
\item
  \texttt{.\allowbreak{}x\allowbreak{}l\allowbreak{}s\allowbreak{}x} workbook exchange
\end{itemize}

This cycle exists to add a true spreadsheet provider adapter on top of the existing workbook seam without dragging spreadsheet-library concerns into the pure runtime/tools packages.

\section{Scope of this cycle}\label{record-193-scope-of-this-cycle}

This cycle intentionally covers:

\begin{itemize}
\tightlist
\item
  a dedicated XLSX adapter package
\item
  serializing an \texttt{E\allowbreak{}x\allowbreak{}c\allowbreak{}h\allowbreak{}a\allowbreak{}n\allowbreak{}g\allowbreak{}e\allowbreak{}W\allowbreak{}o\allowbreak{}r\allowbreak{}k\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k} to XLSX bytes
\item
  parsing XLSX bytes back into an \texttt{E\allowbreak{}x\allowbreak{}c\allowbreak{}h\allowbreak{}a\allowbreak{}n\allowbreak{}g\allowbreak{}e\allowbreak{}W\allowbreak{}o\allowbreak{}r\allowbreak{}k\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k}
\item
  deterministic handling of workbook sheet order and required workbook columns
\end{itemize}

It does \textbf{not} include:

\begin{itemize}
\tightlist
\item
  Google Sheets
\item
  remote services
\item
  filesystem helpers for XLSX paths
\item
  changing the pure \texttt{@\allowbreak{}f\allowbreak{}l\allowbreak{}y\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}r\allowbreak{}o\allowbreak{}b\allowbreak{}o\allowbreak{}t\allowbreak{}s\allowbreak{}/\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}i\allowbreak{}1\allowbreak{}8\allowbreak{}n\allowbreak{}-\allowbreak{}t\allowbreak{}o\allowbreak{}o\allowbreak{}l\allowbreak{}s} workbook model
\item
  changing bundle JSON exchange
\end{itemize}

The point is to prove the provider seam with one richer spreadsheet format first.

\section{Human users}\label{record-193-human-users}

\subsection{Primary human user}\label{record-193-primary-human-user}

A localization maintainer who needs to:

\begin{itemize}
\tightlist
\item
  hand a workbook to translators in a true spreadsheet format
\item
  import edited spreadsheets back into the existing Bijou exchange flow
\item
  keep using the same workbook schema regardless of carrier format
\end{itemize}

\subsection{Human hill}\label{record-193-human-hill}

A maintainer can export and import localization workbooks as \texttt{.\allowbreak{}x\allowbreak{}l\allowbreak{}s\allowbreak{}x} files without losing typed exchange values or inventing a second workbook model.

\section{Agent users}\label{record-193-agent-users}

\subsection{Primary agent user}\label{record-193-primary-agent-user}

An agent automating localization exchange.

It needs to:

\begin{itemize}
\tightlist
\item
  export workbook bytes suitable for XLSX workflows
\item
  parse returned XLSX workbook bytes deterministically
\item
  stay on the same workbook seam as CSV / TSV / filesystem helpers
\end{itemize}

\subsection{Agent hill}\label{record-193-agent-hill}

An agent can automate true spreadsheet exchange without shelling out to ad hoc conversion scripts or bypassing the Bijou workbook model.

\section{Human playback}\label{record-193-human-playback}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  A maintainer exports a German translation workbook.
\item
  They serialize it to an XLSX blob.
\item
  A spreadsheet editor changes translated values.
\item
  The maintainer parses the XLSX blob back into an \texttt{E\allowbreak{}x\allowbreak{}c\allowbreak{}h\allowbreak{}a\allowbreak{}n\allowbreak{}g\allowbreak{}e\allowbreak{}W\allowbreak{}o\allowbreak{}r\allowbreak{}k\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k}.
\item
  They import the rows and merge the translations back into authoring catalogs.
\item
  The resulting runtime catalogs resolve the edited translations correctly.
\end{enumerate}

\section{Agent playback}\label{record-193-agent-playback}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  An agent exports an \texttt{E\allowbreak{}x\allowbreak{}c\allowbreak{}h\allowbreak{}a\allowbreak{}n\allowbreak{}g\allowbreak{}e\allowbreak{}W\allowbreak{}o\allowbreak{}r\allowbreak{}k\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k}.
\item
  It serializes that workbook to XLSX bytes for review or delivery.
\item
  It later parses returned XLSX bytes back into an \texttt{E\allowbreak{}x\allowbreak{}c\allowbreak{}h\allowbreak{}a\allowbreak{}n\allowbreak{}g\allowbreak{}e\allowbreak{}W\allowbreak{}o\allowbreak{}r\allowbreak{}k\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k}.
\item
  It imports the workbook rows and compiles catalogs without losing typed values, refs, or sheet ordering.
\end{enumerate}

\section{Invariants for this cycle}\label{record-193-invariants-for-this-cycle}

\begin{itemize}
\tightlist
\item
  spreadsheet-provider logic must stay out of \texttt{@\allowbreak{}f\allowbreak{}l\allowbreak{}y\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}r\allowbreak{}o\allowbreak{}b\allowbreak{}o\allowbreak{}t\allowbreak{}s\allowbreak{}/\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}i\allowbreak{}1\allowbreak{}8\allowbreak{}n\allowbreak{}-\allowbreak{}t\allowbreak{}o\allowbreak{}o\allowbreak{}l\allowbreak{}s}
\item
  XLSX adapters must preserve the existing workbook schema instead of inventing a new one
\item
  workbook sheet order must remain deterministic
\item
  required translation workbook columns must remain explicit
\item
  service-backed adapters remain out of scope for this cycle
\end{itemize}

\end{itemize}

\section{Proposed API direction}\label{record-193-proposed-api-direction}

The first slice should be close to:

\begin{CodeBlock}
function serializeExchangeWorkbookXlsx(workbook: ExchangeWorkbook): Uint8Array;
function parseExchangeWorkbookXlsx(input: Uint8Array | ArrayBuffer): ExchangeWorkbook;
\end{CodeBlock}

Exact names can still move, but the responsibilities should not.

\section{Tests to write first}\label{record-193-tests-to-write-first}

\subsection{Cycle-owned playback tests}\label{record-193-cycle-owned-playback-tests}

Under \texttt{t\allowbreak{}e\allowbreak{}s\allowbreak{}t\allowbreak{}s\allowbreak{}/\allowbreak{}c\allowbreak{}y\allowbreak{}c\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}L\allowbreak{}X\allowbreak{}-\allowbreak{}0\allowbreak{}0\allowbreak{}6\allowbreak{}/}:

\begin{itemize}
\tightlist
\item
  XLSX workbooks roundtrip through bytes and still import back into runtime-consumable catalogs
\item
  the new package exports only the XLSX-focused workbook adapters
\item
  typed values and refs survive the roundtrip when workbook rows are edited after parsing
\end{itemize}

\subsection{Package-local unit tests}\label{record-193-package-local-unit-tests}

Under \texttt{p\allowbreak{}a\allowbreak{}c\allowbreak{}k\allowbreak{}a\allowbreak{}g\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}i\allowbreak{}1\allowbreak{}8\allowbreak{}n\allowbreak{}-\allowbreak{}t\allowbreak{}o\allowbreak{}o\allowbreak{}l\allowbreak{}s\allowbreak{}-\allowbreak{}x\allowbreak{}l\allowbreak{}s\allowbreak{}x\allowbreak{}/\allowbreak{}s\allowbreak{}r\allowbreak{}c\allowbreak{}/}:

\begin{itemize}
\tightlist
\item
  workbook sheet order is preserved
\item
  required columns survive serialization and parsing
\item
  missing required headers fail clearly
\item
  non-string cell values are normalized back into the exchange row shape correctly
\end{itemize}

\section{Risks}\label{record-193-risks}

\begin{itemize}
\tightlist
\item
  leaking spreadsheet-library assumptions into the pure tools package
\item
  accidentally loosening the workbook schema in order to fit XLSX convenience
\item
  poor error messages for malformed workbook headers
\item
  introducing too much provider-specific policy too early
\end{itemize}

\item
  XLSX filesystem wrappers

  live sync

  changing the exchange row schema

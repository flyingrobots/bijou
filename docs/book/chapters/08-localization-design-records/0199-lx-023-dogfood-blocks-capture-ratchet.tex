\section{Problem}\label{record-199-problem}

The Code Dojo baseline is enforceable, but the repository is not yet living at the standard. The remaining DOGFOOD block and capture surfaces still rely on unsafe casts, implicit string formatting, unchecked reads, and raw user-facing strings. They are also product-facing proof surfaces, so cleanup must preserve rendered behavior and lower-mode truth instead of applying mechanical lint silencing.

\section{Scope}\label{record-199-scope}

\begin{itemize}
\tightlist
\item
  Remove at least \texttt{5\allowbreak{}0} counted ESLint findings from the selected DOGFOOD block and capture cluster.
\item
  Prefer checked reads, local type guards, explicit \texttt{S\allowbreak{}t\allowbreak{}r\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}(\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{})} formatting, and precise return types over assertions.
\item
  Reduce touched raw DOGFOOD strings by removing non-user-facing literals, de-duplicating code tokens, or using catalog-backed lookups when product copy is actually touched.
\item
  Update measured baselines only after validation proves the new counts.
\item
  Update Code Dojo and changelog documentation with landed numbers.
\end{itemize}

The first pass should inspect lint output for the two selected files and group fixes by behavior:

\begin{itemize}
\tightlist
\item
  explicit formatting for numeric and unknown template values
\item
  removal of unnecessary type arguments and unnecessary conversions
\item
  safe external-data narrowing in capture code
\item
  non-null assertion removal around arrays, map lookups, and metadata reads
\item
  raw-string replacement only where the touched code already has localization context available or can be given one without widening architecture
\end{itemize}

If the selected files cannot clear the full target without risky churn, add the next highest small offender only after documenting the reason in this file.

\section{Hill}\label{record-197-hill}

DOGFOOD must stop treating raw visible strings as harmless residue. This cycle removes a material slice from the raw-string baseline by moving selected component story copy behind the existing DOGFOOD localization catalog workflow.

\section{User Experience Contract}\label{record-197-user-experience-contract}

Converted story copy must still read as the same DOGFOOD demonstration. The localized text may use conservative translations, but it must not replace visible content with placeholder keys or intentionally untranslated fallback rows.

\section{Localization And Directionality Posture}\label{record-197-localization-and-directionality-posture}

This cycle uses the existing DOGFOOD localization port. It does not introduce a new directionality model. Any converted copy should continue to flow through \texttt{d\allowbreak{}o\allowbreak{}g\allowbreak{}f\allowbreak{}o\allowbreak{}o\allowbreak{}d\allowbreak{}L\allowbreak{}o\allowbreak{}c\allowbreak{}a\allowbreak{}l\allowbreak{}i\allowbreak{}z\allowbreak{}e\allowbreak{}d\allowbreak{}T\allowbreak{}e\allowbreak{}x\allowbreak{}t} so locale selection, fallback interpolation, and catalog checks remain centralized.

\section{Agent Inspectability And Explainability Posture}\label{record-197-agent-inspectability-and-explainability-posture}

The PR must make the changed keys easy to audit:

\begin{itemize}
\tightlist
\item
  catalog IDs should be grouped by the story surface they serve
\item
  fallback copy should remain adjacent to the rendered usage
\item
  final debt counts should be recorded in this design doc or the PR summary
\end{itemize}

\section{Implementation Outline}\label{record-197-implementation-outline}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}

\item
  Add localization access to the selected component story rendering helpers.
\item
  Convert the selected raw literals to \texttt{d\allowbreak{}o\allowbreak{}g\allowbreak{}f\allowbreak{}o\allowbreak{}o\allowbreak{}d\allowbreak{}L\allowbreak{}o\allowbreak{}c\allowbreak{}a\allowbreak{}l\allowbreak{}i\allowbreak{}z\allowbreak{}e\allowbreak{}d\allowbreak{}T\allowbreak{}e\allowbreak{}x\allowbreak{}t} calls with stable \texttt{s\allowbreak{}t\allowbreak{}o\allowbreak{}r\allowbreak{}i\allowbreak{}e\allowbreak{}s\allowbreak{}.\allowbreak{}*} catalog IDs.

\item
  Regenerate runtime catalogs.
\item
  Run the DOGFOOD i18n gates, focused story tests, and Code Dojo debt checks.
\item
  Ratchet the i18n debt baseline only after the live inventory proves the lower count.
\end{enumerate}

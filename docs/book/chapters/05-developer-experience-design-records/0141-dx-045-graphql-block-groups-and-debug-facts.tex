DX-044 proved the smallest boring path:

\begin{CodeBlock}
GraphQL SDL
  -> bijou-block/1
    -> ui-scene-ir/1
      -> terminal Surface proof
\end{CodeBlock}

DX-045 turns that proof into a more credible authoring pipeline by adding explicit group nodes and deterministic debug facts. It should still stay inside Bijou; Geordi remains the next endpoint after the semantic artifact is strong enough to hand across a repository boundary.

\section{Decision Summary}\label{record-141-decision-summary}

GraphQL-authored Bijou blocks need a hierarchy before Dogfood or BlockLab can use them naturally. The first hierarchy primitive should be a small field-attached group directive, not a general GraphQL execution model.

The next flow is:

\begin{CodeBlock}
GraphQL SDL fixture
  -> bijou-block/1 artifact with groups[]
    -> ui-scene-ir/1 group/text node tree
      -> terminal Surface proof
        -> debug summary facts
          -> ui-scene-receipt/1
\end{CodeBlock}

The debug summary is deliberately fact-shaped. It is not a renderer and not a test snapshot. It gives maintainers and agents one deterministic object that answers what source, artifact, scene, nodes, tokens, i18n keys, actions, bindings, and lower-mode witnesses exist.

\section{Sponsored Human}\label{record-141-sponsored-human}

A Bijou author wants to organize a GraphQL-authored block into named sections without hand-editing JSON IR, then confirm that the rendered terminal output and debug facts still point back to the right source fields.

\section{Sponsored Agent}\label{record-141-sponsored-agent}

An agent wants a deterministic summary of the GraphQL-to-IR pipeline so it can reason about a UI failure from source anchors, group ownership, token refs, i18n keys, bindings, actions, hashes, and lower-mode output instead of interpreting screenshots.

\section{Hill}\label{record-141-hill}

Given a constrained GraphQL SDL file with text fields assigned to named groups, Bijou can produce a stable grouped \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} artifact, lower it into a valid \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1} group/text node tree, render the text nodes to a terminal \texttt{S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e}, and emit deterministic debug facts that preserve source maps, tokens, i18n keys, actions, bindings, lower-mode witnesses, and hashes.

\section{SDL Shape}\label{record-141-sdl-shape}

The first grouped SDL shape stays explicit:

\begin{CodeBlock}
type ReleaseCard
  @bijouBlock(id: "release.card", component: "ReleaseCardBlock")
  @bijouTarget(kind: "bijou-terminal", cols: 48, rows: 8)
  @bijouGroup(id: "release.card.header", label: "Header", x: 1, y: 1, width: 46, height: 3)
  @bijouGroup(id: "release.card.footer", label: "Footer", x: 1, y: 5, width: 46, height: 2) {
  heading: String!
    @bijouText(id: "heading", group: "release.card.header", x: 2, y: 1)
    @bijouI18n(key: "release.card.heading", fallback: "Bijou")
    @bijouToken(fg: "semantic.title.fg")

  openNotes: String
    @bijouText(id: "open-notes", group: "release.card.footer", x: 2, y: 5)
    @bijouAction(id: "release.openNotes", command: "release.openNotes", key: "Enter")
    @bijouI18n(key: "release.card.openNotes", fallback: "Open release notes")
    @bijouToken(fg: "semantic.action.fg", bg: "semantic.action.bg")
}
\end{CodeBlock}

Group directives are type directives. Text fields opt into a group with \texttt{@\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}T\allowbreak{}e\allowbreak{}x\allowbreak{}t\allowbreak{}(\allowbreak{}g\allowbreak{}r\allowbreak{}o\allowbreak{}u\allowbreak{}p\allowbreak{}:\allowbreak{} \allowbreak{}"\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{}"\allowbreak{})}. Omitting \texttt{g\allowbreak{}r\allowbreak{}o\allowbreak{}u\allowbreak{}p} preserves the DX-044 behavior and parents the text node to the block root.

The subset allows only:

\begin{itemize}
\tightlist
\item
  one \texttt{t\allowbreak{}y\allowbreak{}p\allowbreak{}e}
\item
  type directives on the type declaration or following indented lines before \texttt{\{}
\item
  scalar fields
\item
  field directives on following indented lines
\item
  string and integer directive arguments
\item
  group ids that are unique and cannot collide with the root node or field node ids
\end{itemize}

\section{Artifact Contract}\label{record-141-artifact-contract}

\texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} gains \texttt{g\allowbreak{}r\allowbreak{}o\allowbreak{}u\allowbreak{}p\allowbreak{}s\allowbreak{}[\allowbreak{}]}:

\begin{CodeBlock}
bijou-block/1
  id
  component
  sourceHash
  rootNodeId
  groups[]
    id
    label
    source
    layout
  fields[]
    fieldName
    nodeId
    groupId
    text
    action
    binding
    token refs
    source
  targetProfiles[]
\end{CodeBlock}

Existing consumers that only read \texttt{f\allowbreak{}i\allowbreak{}e\allowbreak{}l\allowbreak{}d\allowbreak{}s\allowbreak{}[\allowbreak{}]} remain valid. Lowering owns the new parent-child relationships.

\section{Debug Summary Contract}\label{record-141-debug-summary-contract}

The debug helper should return plain data:

\begin{CodeBlock}
graphql-bijou-block-debug/1
  artifactVersion
  artifactHash
  sceneHash
  rootNodeId
  groups[]
  fields[]
  sourceMap[]
  i18nKeys[]
  tokenRefs[]
  actionIds[]
  bindingIds[]
  lowerModes[]
\end{CodeBlock}

The summary should be stable enough to hash and inspect in tests. It should not include host paths, timestamps, process ids, terminal dimensions from the operator environment, or screenshots.

\section{Accessibility And Lower Modes}\label{record-141-accessibility-and-lower-modes}

Groups must preserve semantic organization even when terminal color and layout are unavailable. Lower modes must still expose:

\begin{itemize}
\tightlist
\item
  node ids for group and text nodes
\item
  i18n keys for localized text
\item
  token refs for styled text
\item
  source anchors for field and group facts
\end{itemize}

No meaning in this slice may depend only on color.

\section{Localization And Directionality Posture}\label{record-141-localization-and-directionality-posture}

The compiler continues to require fallback text for renderable i18n text nodes. Groups may carry labels for debug and inspector use, but group labels are not user-facing localized strings in this slice. Directionality remains deferred until multiline text and localized layout constraints exist in the IR.

\section{Agent Inspectability}\label{record-141-agent-inspectability}

The useful debug path should become:

\begin{CodeBlock}
SDL type directive / field directive
  -> bijou-block/1 group / field
    -> ui-scene-ir/1 group / text node
      -> terminal cell source map
        -> debug summary
          -> receipt
\end{CodeBlock}

An agent should be able to answer, from committed facts:

\begin{itemize}
\tightlist
\item
  Which SDL directive created this group?
\item
  Which fields belong to this group?
\item
  Which visible cells came from a field in that group?
\item
  Which lower-mode output proves the same scene without color?
\item
  Which hashes bind the artifact, scene, surface, and debug summary?
\end{itemize}

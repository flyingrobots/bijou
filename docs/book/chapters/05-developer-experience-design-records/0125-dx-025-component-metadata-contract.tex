\section{Framing}\label{record-125-framing}

Bijou has component facts scattered across package docs, strategy docs, examples, tests, DOGFOOD stories, and MCP-facing payloads. Those surfaces should not each invent a slightly different idea of what a component is.

DX-025 adds a pure component metadata contract in core. The first slice defines the runtime shape, validates common drift, and renders a deterministic summary. It does not build the story workstation; it gives that workstation, DOGFOOD, MCP docs, and agent workflows one shared object to consume.

\section{Sponsored Users}\label{record-125-sponsored-users}

\begin{itemize}
\tightlist
\item
  Maintainers curating first-party component docs and examples.
\item
  Tool builders generating DOGFOOD pages, MCP payloads, or story indexes.
\item
  Third-party authors who want extension metadata without copying internal docs.
\item
  Agent workflows that need stable facts about component modes and invariants.
\end{itemize}

\section{Hills}\label{record-125-hills}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  A maintainer can describe a component's package, family, modes, args, variants, invariants, docs, examples, and source path in one runtime object.
\item
  A tool can validate metadata and get deterministic issue paths for duplicate ids, missing required fields, and empty required lists.
\item
  A docs or agent surface can render a compact summary without parsing markdown.
\end{enumerate}

\section{Drift Check}\label{record-125-drift-check}

\begin{itemize}
\tightlist
\item
  Scope stayed on the contract and validation layer. The story workstation and DOGFOOD migration remain follow-up work that can consume this object.
\item
  Validation catches required-field drift, empty mode lists, duplicate modes, duplicate arg names, and duplicate ids across variants, invariants, and examples. It does not become a schema language or a docs parser.
\item
  Variants and invariants can carry \texttt{M\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}L\allowbreak{}o\allowbreak{}w\allowbreak{}e\allowbreak{}r\allowbreak{}i\allowbreak{}n\allowbreak{}g\allowbreak{}F\allowbreak{}a\allowbreak{}c\allowbreak{}t} records, connecting this contract to DX-026 without coupling metadata to rendered output.
\end{itemize}

\section{Retrospective}\label{record-125-retrospective}

\begin{itemize}
\tightlist
\item
  This gives DOGFOOD and MCP tooling a shared object without forcing either surface to own the component taxonomy.
\item
  Keeping semantic facts attached to variants and invariants should make future story audits and mode-lowering checks cheaper: metadata can describe the intended truth, and render-specific tooling can prove it.
\end{itemize}

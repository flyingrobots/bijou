\section{Decision Summary}\label{record-145-decision-summary}

DX-046 proved that Bijou can compile a checked-in GraphQL SDL fixture into a grouped \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} artifact, lower it into \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, render a terminal proof, and emit deterministic \texttt{g\allowbreak{}r\allowbreak{}a\allowbreak{}p\allowbreak{}h\allowbreak{}q\allowbreak{}l\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}-\allowbreak{}d\allowbreak{}e\allowbreak{}b\allowbreak{}u\allowbreak{}g\allowbreak{}/\allowbreak{}1} facts. DX-048 then defined the V8 contract boundary that VISOR needs to coordinate across Bijou, WARP TTD, Geordi, Bunny, Wesley, and follow-on render targets.

Issue \#458 should be the smallest implementation bridge between those two facts. It should introduce a deterministic \texttt{v\allowbreak{}i\allowbreak{}s\allowbreak{}o\allowbreak{}r\allowbreak{}-\allowbreak{}a\allowbreak{}r\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}t\allowbreak{}-\allowbreak{}b\allowbreak{}u\allowbreak{}n\allowbreak{}d\allowbreak{}l\allowbreak{}e\allowbreak{}/\allowbreak{}1} object that wraps the existing GraphQL fixture source, \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} artifact, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1} scene, debug summary, replay metadata, visual scene facts, and stable hashes. The bundle is a Bijou-emitted proof artifact for VISOR to index; it is not a new VISOR runtime dependency inside Bijou.

\section{Sponsored Human}\label{record-145-sponsored-human}

A maintainer wants one inspectable artifact that says, ``this exact GraphQL fixture produced this exact block artifact, scene IR, debug summary, replay identity, and visual fact set.'' They should not need to reconstruct the proof from scattered test helpers or terminal screenshots.

\section{Sponsored Agent}\label{record-145-sponsored-agent}

An agent wants to load one JSON-shaped bundle and trace a source field through artifact facts, scene nodes, debug facts, replay metadata, visual target facts, and stable hashes without executing DOGFOOD or scraping terminal output.

\section{Hill}\label{record-145-hill}

Given the checked-in DOGFOOD GraphQL fixture, Bijou can emit a deterministic \texttt{v\allowbreak{}i\allowbreak{}s\allowbreak{}o\allowbreak{}r\allowbreak{}-\allowbreak{}a\allowbreak{}r\allowbreak{}t\allowbreak{}i\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}t\allowbreak{}-\allowbreak{}b\allowbreak{}u\allowbreak{}n\allowbreak{}d\allowbreak{}l\allowbreak{}e\allowbreak{}/\allowbreak{}1} whose source, normalized \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} facts, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1} facts, \texttt{g\allowbreak{}r\allowbreak{}a\allowbreak{}p\allowbreak{}h\allowbreak{}q\allowbreak{}l\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}-\allowbreak{}d\allowbreak{}e\allowbreak{}b\allowbreak{}u\allowbreak{}g\allowbreak{}/\allowbreak{}1} facts, replay metadata, visual scene facts, and hash inventory are stable across runs and small enough for VISOR, DOGFOOD, and future WARP TTD tooling to inspect.

\section{Bundle Contract}\label{record-145-bundle-contract}

The first accepted bundle should be plain data:

\begin{CodeBlock}
visor-artifact-bundle/1
  bundleVersion
  fixture
    id
    sourceName
    sourceHash
    normalizedSourceHash
  source
    language
    text
  artifacts
    bijouBlock
    uiScene
    debugSummary
  replay
    replayVersion
    scenarioId
    fixtureId
    deterministicSeed
    steps[]
  visual
    visualFactsVersion
    sceneId
    rootNodeId
    targetProfiles[]
    nodeFacts[]
    lowerModes[]
  hashes
    sourceHash
    normalizedSourceHash
    artifactHash
    sceneHash
    debugSummaryHash
    replayHash
    visualFactsHash
    bundleHash
  receipts[]
\end{CodeBlock}

\texttt{s\allowbreak{}o\allowbreak{}u\allowbreak{}r\allowbreak{}c\allowbreak{}e\allowbreak{}H\allowbreak{}a\allowbreak{}s\allowbreak{}h} records the raw source text hash. \texttt{n\allowbreak{}o\allowbreak{}r\allowbreak{}m\allowbreak{}a\allowbreak{}l\allowbreak{}i\allowbreak{}z\allowbreak{}e\allowbreak{}d\allowbreak{}S\allowbreak{}o\allowbreak{}u\allowbreak{}r\allowbreak{}c\allowbreak{}e\allowbreak{}H\allowbreak{}a\allowbreak{}s\allowbreak{}h} records the semantic source hash inherited from the compiled \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} artifact. \texttt{b\allowbreak{}u\allowbreak{}n\allowbreak{}d\allowbreak{}l\allowbreak{}e\allowbreak{}H\allowbreak{}a\allowbreak{}s\allowbreak{}h} is computed from the canonical semantic bundle payload with raw \texttt{s\allowbreak{}o\allowbreak{}u\allowbreak{}r\allowbreak{}c\allowbreak{}e\allowbreak{}.\allowbreak{}t\allowbreak{}e\allowbreak{}x\allowbreak{}t}, raw \texttt{s\allowbreak{}o\allowbreak{}u\allowbreak{}r\allowbreak{}c\allowbreak{}e\allowbreak{}H\allowbreak{}a\allowbreak{}s\allowbreak{}h} copies, and \texttt{b\allowbreak{}u\allowbreak{}n\allowbreak{}d\allowbreak{}l\allowbreak{}e\allowbreak{}H\allowbreak{}a\allowbreak{}s\allowbreak{}h} itself omitted. That lets VISOR inspect exact source text and raw source identity while preserving a stable semantic bundle hash across whitespace-only SDL edits. Hashing must use the same deterministic JSON rules already used by the GraphQL block and scene IR proof path.

\section{Replay Metadata Contract}\label{record-145-replay-metadata-contract}

Replay metadata is identity and intent, not a full debugger session. The first shape should record:

\begin{itemize}
\tightlist
\item
  stable scenario id
\item
  fixture id
\item
  deterministic seed or explicit no-randomness marker
\item
  source, artifact, scene, debug, and visual hashes consumed by the replay
\item
  ordered steps such as compile source, lower artifact, summarize debug facts, and expose visual facts
\end{itemize}

It must not record wall-clock timestamps, process ids, absolute paths, terminal dimensions from the operator environment, or browser state. WARP TTD may later load this metadata, but WARP TTD does not define the \#458 shape.

\section{Visual Scene Facts Contract}\label{record-145-visual-scene-facts-contract}

Visual scene facts summarize the \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1} output for inspection. They are not Geordi render receipts and not \#459 packed-cell facts. The first shape should expose:

\begin{itemize}
\tightlist
\item
  scene id and root node id
\item
  target profile inventory
\item
  node ids, roles, kinds, text facts, group ownership, and source references
\item
  token refs, i18n keys, action ids, and binding ids
\item
  lower-mode hashes and labels
\end{itemize}

That is enough for VISOR to prove what Bijou thinks the visual scene is before future render targets prove how they draw it.

\section{Failure Cases}\label{record-145-failure-cases}

The bundle builder must reject:

\begin{itemize}
\tightlist
\item
  missing source name or fixture id
\item
  source names that are absolute paths
\item
  missing \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1}, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, or debug summary facts
\item
  artifact, scene, debug, replay, or visual hash mismatches
\item
  duplicate visual node ids
\item
  lower-mode inventories that omit required node, i18n, or token witnesses
\item
  replay metadata that contains host-local or wall-clock facts
\item
  malformed source that the GraphQL block compiler already rejects
\end{itemize}

\section{Accessibility And Assistive Posture}\label{record-145-accessibility-and-assistive-posture}

The bundle must preserve lower-mode witnesses and semantic roles so the proof is inspectable without color, terminal glyphs, or screenshots. Visual facts must name text, node ids, i18n keys, token refs, and source refs independently of the normal terminal rendering path.

\section{Localization And Directionality Posture}\label{record-145-localization-and-directionality-posture}

Renderable text continues to come from GraphQL \texttt{@\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}I\allowbreak{}1\allowbreak{}8\allowbreak{}n} keys plus fallback copy. The bundle must keep i18n keys and fallbacks visible in artifact, scene, debug, and visual facts. Directionality remains deferred until V8 supports localized layout constraints; this cycle must not hide that deferral.

\section{Agent Inspectability And Explainability Posture}\label{record-145-agent-inspectability-and-explainability-posture}

The useful inspection path becomes:

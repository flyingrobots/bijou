\section{Decision Summary}\label{record-142-decision-summary}

DX-044 and DX-045 proved that constrained GraphQL SDL can produce \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1}, lower into \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, render terminal proof, and emit \texttt{g\allowbreak{}r\allowbreak{}a\allowbreak{}p\allowbreak{}h\allowbreak{}q\allowbreak{}l\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}-\allowbreak{}d\allowbreak{}e\allowbreak{}b\allowbreak{}u\allowbreak{}g\allowbreak{}/\allowbreak{}1} facts. DX-046 turns that compiler proof into a real DOGFOOD product fixture.

The first DOGFOOD target is \texttt{N\allowbreak{}a\allowbreak{}v\allowbreak{}i\allowbreak{}g\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n\allowbreak{}L\allowbreak{}i\allowbreak{}s\allowbreak{}t\allowbreak{}B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k} from \texttt{e\allowbreak{}x\allowbreak{}a\allowbreak{}m\allowbreak{}p\allowbreak{}l\allowbreak{}e\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}o\allowbreak{}c\allowbreak{}s\allowbreak{}/\allowbreak{}d\allowbreak{}o\allowbreak{}g\allowbreak{}f\allowbreak{}o\allowbreak{}o\allowbreak{}d\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}s\allowbreak{}.\allowbreak{}t\allowbreak{}s}. It is small enough for a release-boundary slice but real enough to carry product semantics: navigation items, selection state, command intents, i18n text, token styling, group structure, terminal proof, and debug facts.

\section{Sponsored Human}\label{record-142-sponsored-human}

A maintainer wants the post-V7 GraphQL block compiler to prove it can describe an actual DOGFOOD surface, not only synthetic release-card examples.

A DOGFOOD reader benefits because the docs navigation surface becomes inspectable from one source contract instead of only from runtime rendering code.

\section{Sponsored Agent}\label{record-142-sponsored-agent}

An agent wants to trace one DOGFOOD navigation field from SDL through \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1}, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, terminal cells, lower modes, debug summary facts, and receipt hashes without scraping screenshots or reconstructing product intent from rendered text.

\section{Hill}\label{record-142-hill}

Given a checked-in GraphQL SDL fixture for \texttt{N\allowbreak{}a\allowbreak{}v\allowbreak{}i\allowbreak{}g\allowbreak{}a\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n\allowbreak{}L\allowbreak{}i\allowbreak{}s\allowbreak{}t\allowbreak{}B\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k}, Bijou can compile it into a deterministic grouped \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1} artifact, lower it into a valid \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1} scene, render terminal proof, and emit \texttt{g\allowbreak{}r\allowbreak{}a\allowbreak{}p\allowbreak{}h\allowbreak{}q\allowbreak{}l\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}-\allowbreak{}d\allowbreak{}e\allowbreak{}b\allowbreak{}u\allowbreak{}g\allowbreak{}/\allowbreak{}1} facts that preserve source maps, token refs, i18n keys, actions, bindings, groups, lower-mode witnesses, and hashes.

\section{Accessibility And Assistive Posture}\label{record-142-accessibility-and-assistive-posture}

Meaning must survive without color or borders. The \texttt{n\allowbreak{}o\allowbreak{}d\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}d\allowbreak{}s}, \texttt{i\allowbreak{}1\allowbreak{}8\allowbreak{}n\allowbreak{}-\allowbreak{}k\allowbreak{}e\allowbreak{}y\allowbreak{}s}, and \texttt{t\allowbreak{}o\allowbreak{}k\allowbreak{}e\allowbreak{}n\allowbreak{}-\allowbreak{}r\allowbreak{}e\allowbreak{}f\allowbreak{}s} lower modes must expose the same DOGFOOD navigation nodes as the normal terminal proof, and the active selection must be identifiable through source maps and binding facts.

\section{Localization And Directionality Posture}\label{record-142-localization-and-directionality-posture}

Renderable fields must use \texttt{@\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}I\allowbreak{}1\allowbreak{}8\allowbreak{}n} with fallback text. This slice does not add runtime translation behavior or directionality rules; it preserves i18n keys and fallbacks so later locale-aware fixtures can replace the fallback text without changing the artifact contract.

\section{Agent Inspectability And Explainability Posture}\label{record-142-agent-inspectability-and-explainability-posture}

The committed facts should let an agent inspect:

\begin{itemize}
\tightlist
\item
  fixture source path and semantic source anchors
\item
  artifact id, component, source hash, and group hierarchy
\item
  scene id, root node, action ids, binding ids, i18n keys, and token refs
\item
  terminal cell source-map entries for visible navigation text
\item
  lower-mode rows and hashes
\item
  debug summary hash, artifact hash, and scene hash
\end{itemize}

No emitted artifact may include absolute local paths, timestamps, process ids, or screenshots.

\section{Why this cycle existed}\label{record-121-why-this-cycle-existed}

Make command typing match the cleanup-function and runtime-effect patterns Bijou actually encourages.

\section{Why}\label{record-121-why}

The current \texttt{C\allowbreak{}m\allowbreak{}d\allowbreak{}<\allowbreak{}M\allowbreak{}s\allowbreak{}g\allowbreak{}>} typing does not line up cleanly with real usage:

\begin{itemize}
\tightlist
\item
  the pulse timer pattern returns a cleanup function
\item
  the existing type expects \texttt{P\allowbreak{}r\allowbreak{}o\allowbreak{}m\allowbreak{}i\allowbreak{}s\allowbreak{}e\allowbreak{}<\allowbreak{}M\allowbreak{}s\allowbreak{}g\allowbreak{} \allowbreak{}|\allowbreak{} \allowbreak{}u\allowbreak{}n\allowbreak{}d\allowbreak{}e\allowbreak{}f\allowbreak{}i\allowbreak{}n\allowbreak{}e\allowbreak{}d\allowbreak{} \allowbreak{}|\allowbreak{} \allowbreak{}Q\allowbreak{}U\allowbreak{}I\allowbreak{}T\allowbreak{}>}
\item
  consumers end up casting to \texttt{a\allowbreak{}n\allowbreak{}y} to express documented patterns
\end{itemize}

This is both a DX problem and a runtime-model problem, because it blurs the line between commands and effects.

\section{Captured feedback}\label{record-121-captured-feedback}

From \texttt{w\allowbreak{}a\allowbreak{}r\allowbreak{}p\allowbreak{}-\allowbreak{}t\allowbreak{}t\allowbreak{}d} TUI development:

\begin{itemize}
\tightlist
\item
  the pulse timer cleanup pattern required \texttt{a\allowbreak{}s\allowbreak{} \allowbreak{}a\allowbreak{}n\allowbreak{}y}
\item
  the types do not reflect the documented pattern
\end{itemize}

\section{Likely scope}\label{record-121-likely-scope}

\begin{itemize}
\tightlist
\item
  audit current \texttt{C\allowbreak{}m\allowbreak{}d} definitions and real runtime usage
\item
  decide whether cleanup handles, effects, and commands need clearer separation
\item
  align public typing with the documented timer/cleanup pattern
\item
  add tests proving the typed API supports cleanup-producing runtime work without casts
\end{itemize}

\section{Outcome}\label{record-121-outcome}

This work landed and is reflected in \href{https://github.com/flyingrobots/bijou/blob/cbd70612140e7a450d764b3c7be1c6af878b99bc/docs/CHANGELOG.md}{CHANGELOG.md}.

\texttt{C\allowbreak{}m\allowbreak{}d\allowbreak{}<\allowbreak{}M\allowbreak{}>} now matches the cleanup-capable runtime patterns Bijou actually uses, and the runtime retains and disposes cleanup results instead of forcing those paths through fake message contracts.

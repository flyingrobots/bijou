\section{Sponsored Users}\label{record-136-sponsored-users}

\begin{itemize}
\tightlist
\item
  A DOGFOOD reader on a medium-width terminal needs the release-title guide to fit the actual viewport instead of drawing a wider box.
\item
  A TUI author using \texttt{t\allowbreak{}a\allowbreak{}b\allowbreak{}l\allowbreak{}e\allowbreak{}S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e\allowbreak{}(\allowbreak{})} expects readable fitted text by default, matching the word-wrap posture already established by \texttt{t\allowbreak{}a\allowbreak{}b\allowbreak{}l\allowbreak{}e\allowbreak{}(\allowbreak{})}.
\item
  A review agent needs the reported regressions captured as deterministic tests so the branch proves the fix instead of relying on prose.
\end{itemize}

\section{Runtime And API Contract}\label{record-136-runtime-and-api-contract}

\begin{itemize}
\tightlist
\item
  Release-title text rendering must honor the supplied \texttt{w\allowbreak{}i\allowbreak{}d\allowbreak{}t\allowbreak{}h} for interactive mode.
\item
  \texttt{t\allowbreak{}a\allowbreak{}b\allowbreak{}l\allowbreak{}e\allowbreak{}S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e\allowbreak{}(\allowbreak{})} must preserve existing \texttt{o\allowbreak{}v\allowbreak{}e\allowbreak{}r\allowbreak{}f\allowbreak{}l\allowbreak{}o\allowbreak{}w\allowbreak{}:\allowbreak{} \allowbreak{}'\allowbreak{}t\allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{}c\allowbreak{}a\allowbreak{}t\allowbreak{}e\allowbreak{}'} behavior.
\item
  Default fitted string cells should use word-aware wrapping.
\item
  Surface cells that are already structured \texttt{S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e} values may continue to use the existing surface wrapping behavior because the original word boundaries are not recoverable from arbitrary surfaces.
\end{itemize}

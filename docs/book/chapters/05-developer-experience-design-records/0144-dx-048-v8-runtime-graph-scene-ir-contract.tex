\section{Decision Summary}\label{record-144-decision-summary}

\texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}1\allowbreak{}.\allowbreak{}0} proved a constrained path from GraphQL SDL to \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1}, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, terminal proof, grouped debug facts, and DOGFOOD product facts. \texttt{v\allowbreak{}7\allowbreak{}.\allowbreak{}2\allowbreak{}.\allowbreak{}0} stabilized the demo and release surface enough to stop treating that path as release bookkeeping.

The V8 work starts by freezing the product contract before implementation continues. DX-048 defines the source, artifact, IR, receipt, source-map, lower-mode, debug, capture, and witness boundaries that \#458 and \#459 must consume.

VISOR is the coordination surface for the proof. Bijou remains responsible for the source-side contracts and the terminal \texttt{S\allowbreak{}u\allowbreak{}r\allowbreak{}f\allowbreak{}a\allowbreak{}c\allowbreak{}e} proof. Geordi, Wesley, Bunny, WARP TTD, browser renderers, and native renderers may consume or inform the contract later, but they do not define the first Bijou release gate.

\section{Sponsor Human}\label{record-144-sponsor-human}

A maintainer wants V8 to become a stable product contract, not a pile of exciting demos. They should be able to ask, ``what exactly crosses from GraphQL Blocks into Bijou Blocks IR and then into render targets?'' and get a versioned, testable answer.

\section{Sponsor Agent}\label{record-144-sponsor-agent}

An agent needs to trace one product fact from a GraphQL source fixture through artifact fields, scene nodes, terminal cells, lower modes, source maps, debug facts, and receipts without scraping rendered text or guessing ownership.

\section{Hill}\label{record-144-hill}

Given a checked-in DOGFOOD GraphQL fixture, Bijou can produce a deterministic artifact bundle with \texttt{b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}/\allowbreak{}1}, \texttt{u\allowbreak{}i\allowbreak{}-\allowbreak{}s\allowbreak{}c\allowbreak{}e\allowbreak{}n\allowbreak{}e\allowbreak{}-\allowbreak{}i\allowbreak{}r\allowbreak{}/\allowbreak{}1}, \texttt{g\allowbreak{}r\allowbreak{}a\allowbreak{}p\allowbreak{}h\allowbreak{}q\allowbreak{}l\allowbreak{}-\allowbreak{}b\allowbreak{}i\allowbreak{}j\allowbreak{}o\allowbreak{}u\allowbreak{}-\allowbreak{}b\allowbreak{}l\allowbreak{}o\allowbreak{}c\allowbreak{}k\allowbreak{}-\allowbreak{}d\allowbreak{}e\allowbreak{}b\allowbreak{}u\allowbreak{}g\allowbreak{}/\allowbreak{}1}, lower-mode witnesses, source maps, receipts, and packed-cell render evidence, and reviewers can replay the full path without any Wesley or Geordi repository changes.

\section{Contract Sketch}\label{record-144-contract-sketch}

The minimum accepted artifact bundle should be inspectable as plain facts:

\begin{CodeBlock}
graphql-source/1
  -> bijou-block/1
    -> ui-scene-ir/1
      -> packed-bijou-cells/1
        -> terminal-surface-proof/1
\end{CodeBlock}

Each transition must produce a receipt:

\begin{CodeBlock}
receipt/1 {
  fromVersion
  toVersion
  sourceHash
  outputHash
  dependencyHashes[]
  transformFacts[]
  sourceMapRefs[]
  lowerModeWitnesses[]
  debugFactRefs[]
}
\end{CodeBlock}

The receipt is not a logging nicety. It is the review contract. If a future VISOR, DOGFOOD, WARP TTD, or browser proof cannot name the receipt it consumed, it is not part of the V8 release gate.

\section{Failure Cases}\label{record-144-failure-cases}

The V8 contract must reject:

\begin{itemize}
\tightlist
\item
  duplicate source, field, group, node, binding, or command ids
\item
  missing component identity
\item
  missing product facts for a DOGFOOD witness
\item
  broken i18n key references
\item
  broken theme token references
\item
  source spans that cannot map back from artifact or scene facts
\item
  lower-mode witnesses that omit required role or text facts
\item
  packed cells that cannot map to scene nodes
\item
  debug summaries that omit hashes or dependency facts
\end{itemize}

\section{Accessibility Posture}\label{record-144-accessibility-posture}

The contract must preserve lower-mode witnesses. Terminal proof alone is not enough. Every accepted DOGFOOD fixture must expose accessible text and role facts through the artifact or scene receipt so reviewers can inspect a non-TTY representation.

\section{Localization / Directionality Posture}\label{record-144-localization-directionality-posture}

The GraphQL source may reference i18n keys and source-language fallback copy, but it must not smuggle untracked visible copy into the artifact. V8 must keep localization keys visible in debug facts and receipts so DOGFOOD can explain what translated and what fell back.

\section{Agent Inspectability / Explainability Posture}\label{record-144-agent-inspectability-explainability-posture}

Agents must be able to inspect the complete source-to-render chain without executing a full app:

\begin{itemize}
\tightlist
\item
  parse the fixture
\item
  read the artifact
\item
  read the scene IR
\item
  read the receipt list
\item
  read the source map
\item
  read debug facts
\item
  run the terminal proof
\item
  compare hashes
\end{itemize}

This is the line between a demo and a product contract.

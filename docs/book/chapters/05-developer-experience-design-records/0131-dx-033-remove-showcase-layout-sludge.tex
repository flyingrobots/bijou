\section{Framing}\label{record-131-framing}

The old component showcase predates DOGFOOD's \texttt{C\allowbreak{}o\allowbreak{}m\allowbreak{}p\allowbreak{}o\allowbreak{}n\allowbreak{}e\allowbreak{}n\allowbreak{}t\allowbreak{}S\allowbreak{}t\allowbreak{}o\allowbreak{}r\allowbreak{}y} substrate and the v6 storybook workstation. It remains useful as a compact tri-mode example, but it should not keep carrying hand-rolled layout and typing debt now that the primary docs lane has moved elsewhere.

This cycle removes the concrete sludge called out in the v6 bad-code note: \texttt{S\allowbreak{}t\allowbreak{}a\allowbreak{}r\allowbreak{}t\allowbreak{}A\allowbreak{}p\allowbreak{}p\allowbreak{}O\allowbreak{}p\allowbreak{}t\allowbreak{}i\allowbreak{}o\allowbreak{}n\allowbreak{}s} no longer defaults to \texttt{a\allowbreak{}n\allowbreak{}y}, the showcase sidebar no longer does local scroll slicing in the view renderer, and the welcome panel drops its \texttt{w\allowbreak{}i\allowbreak{}d\allowbreak{}t\allowbreak{}h\allowbreak{} \allowbreak{}-\allowbreak{} \allowbreak{}4} sizing shortcut. The full registry rewrite is intentionally not in scope; DOGFOOD and the storybook workstation are now the canonical teaching surfaces for new work.

\section{Drift Check}\label{record-131-drift-check}

The old registry still contains string-first examples. That is acceptable for this cycle because the showcase is now a secondary example surface and many entries intentionally demonstrate string-returning core components.

The key fix is ownership: scroll clipping moves back to the shared list/viewport primitive, and the primary story/doc tooling now lives in DOGFOOD and \texttt{n\allowbreak{}p\allowbreak{}m\allowbreak{} \allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{} \allowbreak{}s\allowbreak{}t\allowbreak{}o\allowbreak{}r\allowbreak{}y\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k} / \texttt{n\allowbreak{}p\allowbreak{}m\allowbreak{} \allowbreak{}r\allowbreak{}u\allowbreak{}n\allowbreak{} \allowbreak{}s\allowbreak{}t\allowbreak{}o\allowbreak{}r\allowbreak{}y\allowbreak{}b\allowbreak{}o\allowbreak{}o\allowbreak{}k\allowbreak{}:\allowbreak{}i\allowbreak{}n\allowbreak{}d\allowbreak{}e\allowbreak{}x}.

\section{Retrospective}\label{record-131-retrospective}

This closes the debt without pretending the legacy showcase should become the new story platform. The right direction is to keep old examples honest while new tooling composes around DOGFOOD stories and shared layout primitives.

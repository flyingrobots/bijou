\chapter*{About this edition}
This book compiles every tracked Markdown document under \path{docs/design/}, including the nested byte-packed Surface record and the design-directory index. It preserves design history rather than presenting every proposal as shipped behavior. GitHub issues and milestones own current roadmap and release scope.

The eight Mermaid source diagrams are redrawn as native TikZ. The component atlas contains vector SVG projections generated from actual DOGFOOD \texttt{Surface} cells at a fixed time, viewport and shipped theme. Source hashes, figure provenance and the complete chapter inventory accompany this edition.

The book palette derives from \texttt{\#F7685F}. Dark coral headings and links contrast at 8.60:1 against white; charcoal body text contrasts at 14.69:1. The anchor coral is used as a field and graphic accent, with dark text at 4.97:1. Component colours retain the actual application theme.

Jacquard 24 and IBM Plex Mono are distributed by \href{https://fonts.google.com}{Google Fonts}. Their SIL Open Font Licenses are included with the font files. DejaVu Sans supplies missing technical symbols. Workstation paths are normalized to portable workspace labels, and selected emoji markers receive plain-language labels. Historical repository links resolve to the archived base revision where applicable.

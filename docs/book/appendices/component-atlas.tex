\chapter{The component cell atlas}\label{component-atlas}

These are deterministic vector projections of actual DOGFOOD component stories at time zero, using the shipped BIJOU\_DARK theme and interactive profile. Every glyph, position, colour and modifier comes from the rendered Surface. The terminal font is explicitly IBM Plex Mono with DejaVu Sans symbols. They are not photographs of an emulator. No component has been redrawn by eye.

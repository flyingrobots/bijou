\section{Historical reasoning}

The separate Design Archive and the complete edition contain the 426 original records, grouped by concern. Locate a record using its original path in the source inventory or the machine-readable manifest. R identities are shared between editions; physical page numbers are edition-specific. A record supplies an argument and evidence to follow, not automatic confirmation that its design is available in the teaching release.

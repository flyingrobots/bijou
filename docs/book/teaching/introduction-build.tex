\addcontentsline{toc}{chapter}{Introduction: Start with a task you can inspect}

The first three workshops turn a small job model into four presentations and then an interactive application. Follow the same facts through each view. The examples use the published release recorded near the front of the book.

\section*{What you will be able to do}

Run checkpoints 01, 02 and 03. You should be able to identify a job independently of its label, explain what each mode preserves, and follow Enter from a key message to a running job.

\addcontentsline{toc}{chapter}{Localization design records}

These records treat language and direction as runtime concerns. They cover localization ports, catalogs, formatting, locale selection, geometry and the application surfaces used to prove the contracts. Distinguish translated content from fallback output, and read debt counts with their inventory definition so an omitted document is not mistaken for a completed translation.

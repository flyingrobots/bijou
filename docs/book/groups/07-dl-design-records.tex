\addcontentsline{toc}{chapter}{Design language design records}

This family connects principles to visible and inspectable interface contracts: patterns, component families, focus and gutter treatment, theme tokens, contrast and rule provenance. Theme Inspector and Theme Lab appear here as concrete surfaces for exercising those ideas. Follow an interaction claim into the implementation and its evidence when using a historical design to understand current controls.

\subsection*{The tested boundary}

The companion passes typechecking and fifteen deterministic tests. A separate local pseudo-terminal check exercised keyboard quit, resize and SIGTERM shutdown and verified restoration of canonical-input and echo flags. The recorded host was macOS arm64. Human screen-reader usability and a broad terminal-emulator matrix were not tested. Linux CI status belongs to the companion's recorded GitHub Actions run. Full local details are in the companion's \path{VERIFICATION.json}.
